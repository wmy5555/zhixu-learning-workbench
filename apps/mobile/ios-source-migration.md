## 需要继续完成的产品验收

本轮没有原生运行环境，因此**完整功能迁移尚未得到 iOS 验收**。以下内容必须作为交接待办，而不能被 23 项 Node 测试代替：

1. 在 Mac 生成工程、CocoaPods 安装、Swift 编译、模拟器启动；修复实际编译/运行诊断。自动链接已找到 ZhixuRuntimeModule，不等于模块能编译。
2. 原生 UI 全流程、VoiceOver、中文输入法、键盘避让、动态字体、深浅主题、iPad 分栏/旋转、返回与中途编辑验收。当前没有 iOS 截图或真实点击证据。
3. 引导原文保留了部分桌面控件名称。原生路线已连接，但桌面定位式讲解及部分扩展步骤的移动端措辞仍需逐步适配和真机走查；不把“显示全课程”当作教程全部完成。
4. 受管插图当前可插入及系统打开；原生阅读器的内联图片布局、复杂 ChatGPT 展示内容与桌面双模式编辑器没有完整视觉等价验收。图片/PDF 不执行 OCR；复杂 DOCX 的表格/脚注/媒体不保证保真。
5. Keychain 锁屏/重新安装、SQLite WAL 与中断恢复、沙箱链接拒绝、TLS 主机验证/固定 IP、取消竞态、断网/超时/未知费用恢复，都要在原生平台测实。没有真实付费供应商验收。
6. 解除 dependency-audit-summary.json 的 2 项 high、1 项 moderate 汇总；本地高危门禁未通过。正式图标、签名、隐私披露、App Store/TestFlight 均未完成。
7. 性能须用合成的 1 千/1 万条资料、长中文/代码/表格、50 MB 单附件和接近备份上限的数据测量。记录启动耗时、主线程长任务、峰值内存、滚动与后台恢复。不得将 Windows 导出耗时当作 iPhone 性能。

## 平台适配及维护约束

- src/core：冻结的桌面业务源码；来源哈希见 baseline.json。业务修改限必要的平台适配：导入平台桥、独立手机草稿排除备份/保护恢复，以及非 Windows 禁用 Windows 专用 Atomics 重试。
- src/services/gateway.mjs：进程内业务分发，不是 HTTP 服务，没有监听端口。不能通过放宽桌面 Host/CSRF 或开放电脑网络来提供手机能力。
- src/platform：Node 适配用于合成契约测试；.native.js 用于 iOS。Metro 明确解析带 .js 后缀的原生适配，防止 Node 内置模块进入 Hermes。
- modules/zhixu-runtime：Swift 私有目录文件操作、设备 Keychain 主密钥和 AES-GCM、DNS、固定 IP 的有界 HTTP/1.1。TLS 使用原主机 SNI 与系统信任验证，不跟随重定向，不自动重试、共享 Cookie 或使用代理。自写网络实现是必须在 Mac/真机重点验证的部分。
- 原生 AsyncLocalStorage 是串行作用域适配，不是完整 Node ALS。可能外发的操作必须串行；只允许同步的设备草稿、任务状态和取消走即时通道。不能把设置、恢复、AI 请求加入旁路。
- 前后台只保留一个生命周期监听。没有后台轮询、常驻服务或可靠后台到点提醒。专注恢复按时间结算，iOS 通知尚未接入。
- 本地文件和 SQLite 使用同步 API；列表虚拟化/分批挂载只能降低渲染开销，不能证明大库读写不会阻塞主线程。大文件当前 base64 桥接有内存放大。
- 凭据密文在独立表内，与设置事务绑定；主密钥在 ThisDeviceOnly Keychain，不进入 JSON 备份。设备草稿也不进入便携备份，恢复拒绝注入 nativeDrafts 命名空间。
- PrivacyInfo 声明仅用于私有目录元数据的 FileTimestamp/C617.1；最终 App 隐私披露须依据真实外发用途和供应商核对。[Apple 原因代码](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons)
