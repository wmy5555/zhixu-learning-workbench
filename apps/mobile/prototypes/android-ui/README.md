# Android 美学原型 · 仅用于选择方向

问题：如何把网页版知序的阅读气质带到原生 Android，而不是把桌面内容堆成一列大卡片？

这是用户明确要求的网页模拟原型。现有原生 RN 页面不能直接承载静态 HTML，因此在移动端相邻目录新增独立 prototype 路由，不挂接正式 4318 或 Android 包。

## 查看

从仓库根目录运行：

```sh
node apps/mobile/prototypes/android-ui/serve.mjs
```

打开 http://127.0.0.1:14348/prototype/android-ui?variant=A 。端口可由 `PROTOTYPE_PORT` 指定，只监听回环地址；`NODE_ENV=production` 时拒绝启动。也可直接打开 index.html：全部 CSS、图标和交互内嵌，离线使用 hash 保持方案选择。

底部浮动工具条切换 A/B/C，左右方向键也可切换；输入框和中文输入法组合状态不会被方向键快捷操作打断。工具条展示当前方案、页面、外观与示例数量。预览控件和说明不属于拟定 App 界面。

## 三个结构方向

- A「静读书桌」：编辑式标题、日期、单张主卡片、紧凑安排和轻量入口。推荐方向，最贴近用户提供的网页版。
- B「一页手记」：日期索引、先记录想法、引用与线性条目，不使用首页卡片网格。
- C「专注一刻」：围绕一次学习展示时间、问题和主动作，后续事项收在末端。

今日、收集、知识库、学习、应用均可进入。主要差异体现在首页的信息结构，并延伸到记录、资料和学习页面；共用颜色、底部导航和基本控件，避免形成三个长期产品。

示例可执行收集→保存→阅读→编辑，以及练习、筛选和输出排版演示。处理选项保持前置依赖：关闭 AI 拆解会禁用并清掉联网检验。没有真实 AI、文件导入、计时或真实学习评分。所有正文为原创合成示例，无本机资料、账户或凭据；关闭或刷新后重置。CSP 禁止网络连接，没有外部脚本、字体和资产依赖。

## 设计来源与取舍

参考用户提供的五张 Android 页面与一张网页版截图，只用于目视理解，没有把截图或其路径放入公开产物。参考 `Caho1/open-claude-ui` 固定提交 `4045ce76afdcb7dccef1b7e6417b04c4c6046e9c` 的实际主题源码：暖灰表面、陶土品牌色、细线边界、系统字体回退与 `cubic-bezier(.16,1,.3,1)`。许可保留在 REFERENCE-LICENSE.txt，不替知序项目选择许可证。

针对知序调整深色画布至 #1a1a18、次表面 #242421，保留网页版暖灰阅读感。标题使用本机 CJK 宋体回退，未复制专有字体；系统没有对应宋体时外观会不同，真正落地原生版本须另行确定可分发字体。图标与植物线稿为本原型自绘 SVG。

状态栏、页面头部、滚动内容与底部导航各占独立布局区。手机原型为 390px 宽度检查；桌面模拟器保持完整手机比例再缩放，不把设备内容裁进桌面窗口。实际 Android 的系统安全区域、字体缩放和键盘仍须在原生实现时适配，本网页不证明设备修复完成。

## 实际检查与结论

只进行必要的语法与浏览器检查，没有添加测试套件、安装依赖、构建 APK 或运行产品回归。已在 Codex 浏览器查看三种布局和深浅模式，走通一份合成资料的保存→阅读，核对处理开关依赖、五个主入口、空白库和 390px 无横向溢出；未观察到浏览器错误。

推荐 A，用户尚未选定。保留 A/B/C 作为设计依据，下一步应根据用户选择实现原生组件，不能直接把本原型装进 WebView 或合入正式产品。分支 `chore/android-ui-prototype-20261023` 仅保存原型，不创建提前 PR、不合并、不部署正式 4318。PR96/98 更新状态与本聊天已处理记录一致，无新的相关反馈；无当前任务 PR，未请求云端审查。
