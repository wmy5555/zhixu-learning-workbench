# Android 界面原型

当前默认预览为用户选定的组合方向 **D「随身书桌」**，继续只做网页原型，不改 Android/iOS 原生实现或正式 4318。

在本工作树运行：

```powershell
node apps/mobile/prototypes/android-ui/serve.mjs
```

打开 http://127.0.0.1:14348/prototype/android-ui?variant=D 。支持 page=today|capture|library|study|output、theme=dark|light、scene=sample|empty。底部原型工具条保留 A/B/C 对照，默认 D；这条工具条不属于拟定 App。离线 index.html 自包含，file: 用 hash 记录预览选项。所有内容仅在内存，刷新重置，不发出网络请求。

## 排版与动效来源

颜色、阅读层级沿用 open-claude-ui 固定提交 4045ce76afdcb7dccef1b7e6417b04c4c6046e9c 与知序 UI 指南。MIT 文本见 REFERENCE-LICENSE.txt。系统 CJK 宋体回退、自绘 SVG，不新增字体或媒体资产；原生字体方案待 Android 实现。

本轮按用户要求参考 [emilkowalski/skills](https://github.com/emilkowalski/skills)，实际读取已安装 emil-design-eng、animate 及其 recipes：高频导航轻量反馈，侧栏沿来源方向进出，可打断 transition，只对 transform/opacity 做位移与显隐动画，键盘与减少动态效果即时响应。双语标题是本项目排版选择，不声称上游规定双语格式。

- 底栏标记：180ms，cubic-bezier(.77,0,.175,1)；同一个标记 DOM 保留，连续切换可重新定向，页面内容即时切换。
- 侧栏：进入 240ms、退出 200ms，cubic-bezier(.32,.72,0,1)；遮罩 opacity 200ms，复用 CDS ease。没有大面积模糊、轮询或新增动效依赖。
- 侧栏用浏览器原生 dialog 提供模态焦点、背景不可操作和 Escape，按模拟手机的实际缩放定位，避免升级成全网页弹窗。这里为纯 HTML，不为复用 React 组件库引入构建链。
