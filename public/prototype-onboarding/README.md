# 渐进式探索原型 02：固定地图

问题：新手探索能否像揭开一张地图，完成后直接留下可以继续使用的工作台？

用户否定第一版完成后收缩、重排的 A/B/C 卡片布局。本轮收敛为一个方案：从始至终固定四个区域；解锁只改变遮罩、可访问状态和导航标记。旧 A/B/C URL 均显示当前固定地图。旧实现保留在历史提交 e5871f9，不作为当前候选。

## 打开与体验

在独立工作树运行 `pnpm prototype:onboarding`，访问 http://127.0.0.1:4349/ 。无须安装依赖。也可执行 `node public/prototype-onboarding/serve.mjs`。

固定位置：左上收集、右上知识库、左下今日学习、右下输出。点击第一束光 → 放入示例并收集 → 在知识库打开原文并加入学习 → 写下理解并保存 → 引用理解、编辑并保存草稿。

从首帧起，四个区域都是同一组 DOM 节点、同一套 45%/55% 列和 50%/50% 行。雾层下的控件 inert、aria-hidden；当前区域可操作；完成的区域继续可用，不再缩成摘要、不重新排列、不弹出取代主界面的完成页。资料列表在自身区域内滚动，输出编辑框一直留在原处。侧栏对应入口也保留固定位置。

小叶子虚拟鼠标沿用正式实现的移动、框选和波纹。新区域以固定裁剪的雾层透明度消退显露，并附轻微阻尼回弹；已经探索过的区域不参与后续入场动画。减少动态效果时直接显示终态。重置恢复四片雾、空输入和锁定状态。

## 参考与边界

- 参考 [Sky 官方地图说明](https://thatgamecompany.helpshift.com/hc/en/17-sky-children-of-the-light/faq/1104-what-is-the-sky-map/?p=web) 中“激活后永久揭示所在区域”的规则，以及地图的暗底、等高线、路径和微光标记。未复制游戏图片或其他游戏资产；地形线由本原型 SVG 绘制。
- 原型自带深浅色。使用 [Dark Reader 官方页面声明](https://github.com/darkreader/darkreader/blob/main/CONTRIBUTING.md#disabling-dark-reader-on-your-site) 避免浏览器扩展二次染色；不修改扩展的全局或站点设置。雾层使用透明度，不依赖可能被改色的黑白亮度蒙版。
- 只有本页内存数据，刷新或重置清空。可以在本次体验中持续使用，不代表已做长期数据持久化或接入真实知识库。CSP 禁止网络连接，无 AI 调用、正式数据写入、真实学习成绩或教程进度。
- 仍在独立分支 feat/prototype-progressive-onboarding-20261022。未同步正式 4318、未改桌面启动入口、不创建 PR；原型未经采用，不作为日批产品部署内容。
- 本轮增量核读当前分支 PR 查询，结果为空；前一轮已读 #91/#94 意见仍不涉及本原型路径，不重复全量审阅或触发云端请求。
- 虚拟鼠标来自正式 library-return-20261021 的 public/web/onboarding-motion.mjs。物理函数来自 Caho1/open-claude-ui 固定提交 4045ce76afdcb7dccef1b7e6417b04c4c6046e9c，MIT 声明仍在 cds/LICENSE.txt。未改变项目许可证。
