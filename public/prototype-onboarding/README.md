# 渐进式新手探索原型（可丢弃）

问题：把知序从一张空白工作台逐块展开，能否让第一次探索更轻松，并有适度的游戏感？当前等待用户体验，尚未选定方案，不能据此改正式产品。

在此独立工作树运行 `pnpm prototype:onboarding`，访问 http://127.0.0.1:4349/?variant=A 。无需安装依赖。也可运行 `node public/prototype-onboarding/serve.mjs`。

- A 地图生长：保留探索过的区域，工作台随步骤展开。
- B 章节探索：已完成区域收成章节索引，一次只展示一处操作。
- C 路径漫游：沿纵向路径展开区域，把探索过的地方连起来。

底部箭头或键盘左右键切换方案，不清除本次进度；输入框中的方向键仍用于编辑。重新探索和刷新清空内存状态。状态按钮显示完整的相关解锁状态。

体验路径：开始探索 → 放入示例并收好 → 展开知识并带去学习 → 填写理解并确认 → 选择引用并生成示例卡片 → 完成。所有解锁均由对应的显式操作触发。后续区域在解锁前不渲染，不可点击或聚焦。已完成区域和侧栏可回看，不能跳过未完成区域。

所有内容均为合成示例或当前页面输入，只在内存中停留。CSP 禁止网络连接；无 AI 调用、知识库写入、学习成绩、正式教程进度或跨刷新持久化。没有复制正式数据。预设知识和输出排版明确标注为演示。此原型不进入正式 4318，不纳入自动日批产品部署。

## 来源与边界

- 原型位于隔离分支 `feat/prototype-progressive-onboarding-20261022`，基于最新远端 main `6082b6a`。未修改主工作区已有改动，也不更改桌面启动入口或服务。
- 虚拟鼠标直接复用当前正式工作树 `library-return-20261021` 的 `public/web/onboarding-motion.mjs`；所需 `sidePosition`/`intersection` 和 SVG 图标从同一来源最小提取。不重新实现其移动、框选、波纹或滚动跟随。
- 新区域使用原生 Web Animations 采样阻尼弹簧，采用固定参考实际源码的 `SPRING_GENTLE`（380/18/1），侧栏使用 `SPRING_SNAPPY`（320/28/1）。与文档表格不一致时遵循源码。弹性限于区域出现与反馈，不持续摇晃。
- 配色、系统中文字体、留白与现有知序保持一致。无下载图片、外部字体或音频；深浅色仅留本页，不写用户偏好。减少动态效果时不执行弹簧、波纹或平滑滚动。
- 物理辅助函数源自 Caho1/open-claude-ui 固定提交 `4045ce76afdcb7dccef1b7e6417b04c4c6046e9c`，MIT 声明保留在 `cds/LICENSE.txt`。未选择或更改知序项目许可证。
- 修改前核读 PR #91、#94 的评论、行内意见及审阅总结。#91 Escape 已有修复回执；永久删除授权和 #94 长来源引用性能意见不在本原型范围，未调用这些路径，不将其概括成已全部处理。本原型没有当前 PR，不额外发送云端审查评论。

正式整合前仍需重新设计与真实 28 步教程的证据、恢复、跳过和权限边界的映射；此处的四区域节奏只用于观察 UI 效果。

## 实际验证（2026-10-22）

桌面 Chrome 1419 × 919：初始无内容区域、侧栏只有今日；空收集输入、未打开知识、空回答、未选择引用均保持下一步按钮禁用。按显式操作走完四区域，结尾 4/4 完成、无当前操作区。切换 A/B/C 保留 4 个完成状态，重置后回到 0 区域。知识库阶段读回恰有 2 区域且学习按钮禁用；完成前不会渲染输出区域。

实际检查深浅模式、桌面布局、虚拟鼠标移动/框选、输入框左右键不切换方案、桌面无横向溢出。模拟 prefers-reduced-motion 后读回 0 个动画，仍能正常展开区域；恢复常规动效后回到 A 的初始页。页面 fetch/XHR 资源数 0，没有实际 AI 或正式数据验收。

内置浏览器控制受沙箱初始化故障影响不可用；改由 chrome-use 检查。原生点击出现 daemon disconnected 且动作可能已执行，先读回状态，再以浏览器 DOM 原生 click 和表单事件逐步验证，没有将工具错误当成功。无新增自动化测试，无全套产品回归。依用户要求跳过窄屏检查。

项目 `pnpm check` 实际通过，扫描 349 个跟踪文件；差异空白检查通过。首次脚本括号语法和复制文件 CRLF 检查失败均在交付前修正。可见 Chrome 中采样到新区域横向缩放 0.91 → 1.01743 → 接近 1，确认有实际回弹；后台标签的动画帧测量超时不算通过。主动定位期间取消稍后自动定位，避免打断用户框选。
