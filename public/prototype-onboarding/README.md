# 知序认知地图原型 03

本原型回答：能否用同一张有层级的地图，同时承担新手探索、功能架构和日常导航？

## 运行
在本独立工作树运行 pnpm prototype:onboarding，打开 http://127.0.0.1:4349/?revision=cognitive-atlas 。
无须安装依赖；等价命令为 node public/prototype-onboarding/serve.mjs。
复杂设计说明见 [层级与导航](architecture.html)，由 answer-me-with-html CLI 根据项目设计文档生成。

## 当前方向
三类永久内容仍为原始资料、结构化材料、用户确认的个人理解。
地图中的五段是功能路径：收集资料 → 整理知识 → 学习与复习 → 个人理解 → 检索与应用。
侧栏从上到下，地图从下到上；各模块的三个二级分组由同一份目录渲染。
模型与权限、节奏与成本、文件与恢复、外部连接、外观偏好放在共同支撑区。
当前只保留这一方向；此前 A/B/C 和四宫格原型在历史提交中，不是当前候选。

暖纸底色、系统中文字体、轻地形轮廓和疏朗连线沿用知序风格。
地图节点位置固定。完成步骤只改变解锁、连线和标记，右侧操作区随选择切换。
全图模式允许查看未来模块的完整功能，但不会解锁或伪造教程进度。
已探索区域可以继续使用。输入写入本页状态，切换模块保留尚未提交的文字。
个人理解要求明确勾选确认；修改文字立即清除确认。
没有生产数据、供应商请求、真实批改、掌握判断或跨刷新保存。
