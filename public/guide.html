知序 · 新手使用指南

从一份资料，走到自己的理解

知序帮助你保存看到的内容、整理值得学习的知识，再通过解释、复习和实际使用形成自己的理解。第一次使用，只需走通一条小流程，不必先配置所有功能。

保存原文 → 整理知识 → 选择用途 → 自己解释 → 确认理解 → 复习与使用

从第一次体验开始 ↓

01　先完成一次体验

没有 AI 密钥也能开始。下面用明确标识的演示资料熟悉操作；AI 反馈需要另行配置。

  1. 打开工作台。在项目文件夹双击 start.cmd，浏览器会打开本机工作台。若未自动打开，访问 http://127.0.0.1:4318。首次在新电脑使用，需要先安装 Node.js 24 或更新版本，再运行 install.cmd。
  2. 设置每天的投入。打开「系统 → 能力设置」，检查每天计划学习多久、日程时区、生成清单时间和笔记存储位置，点击「保存能力设置」。已有资料时保持原来的存储位置。
  3. 先从系统导入演示资料。演示资料的导入入口位于「系统 → 备份与恢复 → 完整备份」区域。前往演示资料导入入口（新标签页）↗，点击「导入演示资料」并确认。它会加入标为演示的内容，不会替你生成已掌握记录。
  4. 导入成功后，再到知识库开始学习。只有完成上一步，知识库才会出现演示内容。打开「演示知识 · 给读书报告保留出处」，选择「加入学习」，写下理由，例如“先熟悉主动回忆的操作”。如果找不到，请先回到上面的导入入口完成导入。
  5. 自己回答一次。进入「学习与错题 → 学习队列」，点击「开始学习」。先阅读，再点「隐藏材料，开始回忆」，用自己的语言回答并提交。
  6. 确认自己的理解。回答保存后，点击「整理并确认个人理解」，修改文字，再点「确认写入」。没有 AI 时可以独立完成这一步；等待反馈不代表回答丢失，也不代表 AI 已经批改。
完成标志：你能在「最近学习记录」找到自己的原回答，并在知识详情看到经你确认的个人理解。完成一次练习不等于永久掌握；之后还要复习或应用。

想直接用自己的内容？跳到「收集与整理资料」。不想导入演示也不影响使用。

02　认识工作台

先分清三类内容：原始资料保留别人说了什么；整理后的知识记录概念、证据和条件；个人理解记录你自己能解释什么。AI 的整理结果不会自动成为你的个人理解。

入口什么时候用
今日按当天时间预算开始学习、复习，查看安排理由，延期或跳过任务。
收集与加工粘贴原文、补充出处，或批量导入文本文件。
知识库查看原文和资料拆解，编辑内容，选择学习用途，确认个人理解。
学习与错题阅读、主动回忆、接受反馈、继续学习记录，以及处理错题。
主题学习包围绕一个问题组织已有知识，记录学习顺序和前置缺口。
检索与发现搜索资料，查看关联建议和发现报告，决定是否接受联系。
问答与输出用已有材料回答问题、组织提纲或生成草稿，检查实际引用。
系统设置 AI 和学习计划，查看任务与调用记录，备份恢复、审阅写入提案及冲突。

左下角 ? 随时打开本指南。查看帮助不会切换工作区；点击右上角关闭、按 Esc 或点击弹窗外侧即可返回。窄屏上的主要导航由左上角菜单按钮展开。

03　收集与整理资料

保存第一份真实资料

  1. 进入「收集与加工」，填写标题并粘贴原文。可以是文章摘录、你已取得的视频转录文字或 AI 对话；对话尽量保留角色和上下文。
  2. 补充平台、作者、原始地址、日期及页码或时间点。不知道的留空。仅填写链接不会自动抓取全文，也不会自动读取其他 AI 产品的聊天历史。
  3. 检查“仅本地”勾选框。当前粘贴表单初始未勾选；希望内容只留在本机时请主动勾选。不勾选会把这份资料标为允许云端，但是否调用服务还取决于能力设置及后续操作。
  4. 第一次可以先不勾选“保存后提交 AI 拆解与核验任务”，点击「保存原始资料」。然后到「知识库」打开这份资料，确认原文确实保存。

导入多个文件时，在「批量导入」选择 UTF-8 编码的 .txt 或 .md，再点击「导入所选文件」。每个文件独立保存为原始资料，当前批量导入默认仅本地且不自动加工。PDF、图片、音视频需要先自行取得可用文字。

选择手动整理或 AI 加工

手动：打开原始资料，点击「手动整理为待选学」，填写标题、整理后的正文、保留理由、目标深度和可选主题。含事实的内容应保持“含需查证事实”；它会保留待研究限制。只有确实是个人观点或虚构练习时才选择另一项，不要靠改类型绕过事实核验。

AI：先按「启用 AI 与联网」完成设置，再在「编辑原始资料」中允许这份资料云端处理，保存后点击「提交拆解与核验」。也可在初次保存时一并提交加工任务。

加工后，到「知识库」打开原始资料卡片：上方可展开「查看原始资料全文」，下方「资料拆解」集中展示它产生的知识。阅读正文中的结论、依据、反例和限制，区分原作者的说法、外部证据和 AI 的整理。

“尚需补充研究”表示仍有实质问题待解决，这些事实暂不能用于默认学习计划或有据回答。可到「系统 → 任务」查看原因，解决配置、网络或额度问题后再重试。保存成功与加工完成是两件事。

04　选择学什么

不必把所有收藏都变成学习任务。在知识详情或「资料拆解」的操作区选择用途，并写出真实理由。

学习状态适合的情况
仅供查阅以后能找到就够了，例如操作参数、资料出处。
待选学可能有用，先留着；暂时不投入学习时间。
正在学习近期值得解释或应用。点击「加入学习」，进入学习池。
已整理个人理解已亲自写下并确认理解。仅标记状态不能代替确认文字。
重点知识已确认理解，且值得长期复习和跨场景使用。可从更多操作中设置。
不再使用内容过时、被替代或不再适用，退出默认教学和现行答案。

目标深度也可以不同：知道存在、知道去哪找、能够解释、能够迁移应用。理由可以很具体：“下周写课程报告需要解释这个机制”，比“很重要”更方便日后判断。

加工任务队列、学习池和今日清单彼此独立。导入十份资料，不表示今天必须学十份；加入学习，也不一定立刻排进今日预算。

05　学习、复习与纠错

  1. 在「今日」点击任务的「开始」，或在「学习与错题 → 学习队列」选择「开始学习」。
  2. 先阅读必要材料，再点击「隐藏材料，开始回忆」。用自己的语言解释问题、机制、条件和可能失效的情况。
  3. 想不起来可以用「分级提示」或「查看原文（记为提示）」。提示使用会被记录，不需要假装独立答出。
  4. 「提交回答」后，配置可用时会安排 AI 反馈。关注具体遗漏、修正依据和下一步追问；等待时可点「刷新反馈」，不要反复提交同一回答。
  5. 点击「整理并确认个人理解」，亲自修改最终文字后「确认写入」。也可以在知识详情中直接「确认个人理解」。
不知道怎样解释？

试着写：“它解决的问题是……；成立的条件是……；我能举的例子是……；如果……，这个结论可能不适用；我还不确定的是……。”

每天怎样用

打开「今日」，查看安排理由和预计耗时；需要时点击「生成今日清单」。时间不够可「延期」或「跳过」，无需为清空列表而伪造完成。调整长期投入，在「系统 → 能力设置」修改每日时间、优先主题和日程。

离开后可从「学习与错题 → 学习队列 → 最近学习记录」点击「继续」。已提交的回答会保留；尚未提交的输入请先保存再刷新或离开。

AI 判错时

打开「学习与错题 → 错题库」，查看当时问题、原回答、遗漏和修正依据。不同意时点「质疑判定」并说明理由；确实修正后点「标记已纠正」。有争议的记录可以「重新打开」。错误答案不会作为普通正确知识进入默认问答。

关闭浏览器不等于关闭服务：服务继续运行时才可能自动安排和处理任务。电脑关机或休眠时不保证执行，恢复运行后补算今天。要停止后台服务，双击 stop.cmd。

06　围绕主题学习

当几条知识共同服务于一个问题时，在「主题学习包」点击「新建主题学习包」。用问题命名，例如“我怎样判断一条搜索结果是否可靠？”，填写要解决的问题与边界、预计投入、缺失的前置知识，并勾选相关内容。

在正文中写明建议顺序。暂时不学时可「暂停」，之后「恢复」。当前编辑页可修改标题、问题、顺序说明、时间和前置知识；要重新组合成员，请新建主题学习包。首次选择列表最多显示前 100 条。

「AI 建议学习包」只使用允许外发的材料，产生可审阅的「AI 整理建议」。它不会自动建立正式主题；读过建议后，再手动创建并采用。可以到「知识库」按内容类别查找建议，任务进度在「系统 → 任务」。

07　查找、关联与输出

先找得到，再用得上

在「检索与发现」输入术语或问题，点击「搜索」。默认使用本地关键词检索，不需要 AI。找不到时先减少筛选、缩短关键词，再展开来源、主题和时间筛选缩小范围。

想用不同说法找相近概念，需先配置语义嵌入并「重建索引」，然后勾选“允许将本次查询发给已配置的外部服务”，选择「语义」或「混合」。仅本地资料仍受外发限制；未建立向量的内容不能期待获得语义匹配。结果中的相关度表示匹配程度，不是事实正确率。

在关联建议中看清联系的依据、用途和失效边界，再接受或拒绝。词语相近不等于存在因果关系；发现报告是待审阅的线索。

用材料回答问题或写作

  1. 进入「问答与输出」，写下问题或输出目标，选择「回答问题」「组织提纲」或「生成草稿」。
  2. 勾选取材范围：知识笔记、原始来源。默认不允许问题外发，此时只在本机检索并列出已有材料。
  3. 需要模型生成时，启用文本生成，并勾选“允许将本次问题发给已配置的外部模型”。只有标为允许云端的相关材料可外发。
  4. 点击「开始生成」，阅读结果、限制和「实际引用」，用「打开材料」回到来源检查。没有引用的内容不要当作有据回答。
  5. 在「输出工作区」编辑已保存的草稿，勾选实际采用的知识，再「保存草稿」。想继续沉淀的文字可以「送回收集箱」，重新进入原始资料流程。
RAG（检索增强生成）就是先找相关材料，再交给模型组织答案。找到了材料仍需要检查它是否真正支持结论；问答、提纲和草稿不会自动成为你已经掌握的知识。

08　启用 AI 与联网

打开「系统 → 能力设置」。按你要完成的事情开启能力，无需一次填完所有设置。

能力用途与需要填写的内容
文本生成AI 拆解、学习反馈和生成回答。填写兼容接口的服务地址、模型名称和 API 密钥，再启用。
联网搜索寻找核验线索。填写兼容搜索服务的地址和密钥；它与文本生成单独配置。
公开网页读取读取搜索得到的网页正文。需要单独启用；搜索摘要不等于已读原文。
语义嵌入支持换一种说法查找资料。填写嵌入服务地址、模型和密钥；不必与聊天模型相同。
  1. 填写并启用所需能力，先点击「保存能力设置」。连接测试使用已保存的设置。
  2. 分别运行「测试连接」「测试搜索」「测试网页读取」或「测试嵌入」。测试可能产生外部请求和费用。某一项成功不代表其他能力也可用。
  3. AI 事实加工通常需要文本生成、联网搜索及网页读取三项能力；仅保存和本地查找不需要这些能力。
  4. 需要语义检索时，在「系统 → 诊断与 MCP」点击「重建索引」，再到「任务」确认完成。

资料权限与提问权限分开。允许一份资料云端处理，并不等于所有资料都获授权；搜索和问答中还要决定是否外发本次查询。密钥保存后不会回显，留空表示保持原值。当前服务端点要求公开 HTTPS 地址，不支持连接本机模型端口。

「每日外部请求总上限」统计模型、搜索、读取等外部请求，不是“每天可以整理多少篇”。长资料可能消耗多次请求；月预算为 0 表示未设置月上限，费用无法获得时显示“未知”。在「诊断与 MCP」检查调用记录、耗时和失败原因，实际费用以供应商账单为准。新手可先保留默认提示词。

什么时候需要 MCP

MCP（模型上下文协议）让支持它的外部 AI 应用调用你的知识搜索和读取工具。仅使用本网页无需启用。需要接入时，在能力设置中启用本地 MCP，并按项目的 docs/MCP.md 配置兼容客户端，在「诊断与 MCP」核对实际调用。允许写入提案后，修改建议仍需你在「系统 → 写入提案」审阅并接受才会写入。

09　保存与备份数据

笔记存储文件夹也叫 Vault，其中的 Markdown 是可直接阅读的文本笔记。你可以用 Obsidian 打开同一个文件夹；日常使用不要求安装或打开 Obsidian。学习记录、任务、草稿等另存在应用数据中，所以只复制笔记文件夹不等于完整备份学习进度。

  1. 备份：在「系统 → 备份与恢复」点击「下载备份」。在大批量修改、删除、合并或恢复前保留一份。
  2. 恢复：选择此前下载的 JSON 文件，点「先预览恢复」，检查内容后再「确认恢复」。执行前系统会生成安全备份。
  3. 附件另存：JSON 备份包含受管理的笔记和运行学习记录，不含 API 密钥、MCP 令牌，也不含外放的图片、PDF、音频和 Obsidian 配置。这些请随整个 Vault 另行复制；换电脑需重新配置密钥。

在 Obsidian 等外部编辑器修改后，回到网页刷新查看。出现冲突时去「系统 → 冲突」检查，不要直接用旧正文覆盖新内容。单条笔记可通过「查看版本」检查历史并按需要恢复；删除当前笔记不等于清除以前的历史和备份。

「重建索引」重新整理搜索目录，不是恢复已删除笔记，也不会替你补出学习记录。本产品目前面向本机单用户，未提供手机同步、多人协作或公网访问。

10　遇到问题怎么办

资料保存了，为什么还没有拆解？

保存只代表原文入库。先打开原始资料确认是否提交「拆解与核验」，再到「系统 → 任务」看状态和原因。核对资料是否允许云端，以及模型、搜索、网页读取是否已保存、启用并测试。

显示“等待条件”“已保存，待继续”或失败

先读任务原因。额度用尽时等待恢复；缺配置时补齐；网络或模型超时先检查连接。条件解决后，在「系统 → 任务」重试，或取消不再需要的任务。服务重启后中断的外部任务也可能需要重试。不要通过重复导入原文催促处理。

任务已完成，就代表所有事实都确定了吗？

不是。任务状态只说明处理流程是否结束。仍需阅读知识正文中的证据、适用条件、研究限制和核验时间；“尚需补充研究”的内容不能当作现成学习结论。连接测试成功也不能证明后续整条学习流程的质量。

今日清单或学习队列为什么是空的？

先在知识详情「加入学习」，再到「今日」生成清单。仅供查阅和待选学不会自动变成当天任务；研究限制、暂停项和时间预算也会影响安排。暂未排入今日的正在学习内容，可到「学习与错题 → 学习队列」查看。

回答已经提交，为什么一直没有 AI 反馈？

原回答会先保存，批改单独排队。去「系统 → 任务」查看批改原因，解决后重试，再回学习页刷新反馈。也可先整理并确认自己的理解；没有收到反馈时，不要把等待当成“答对了”。

语义检索选不了，或搜不到已保存内容

语义和混合检索需要允许本次查询外发、启用嵌入服务并完成索引。先用本地关键词查找，清空多余的主题、阶段和日期筛选；检查材料权限、内容是否仍存在或处于冲突状态。只有允许云端的内容可进入外部嵌入流程。

问答只列出材料，没有生成完整答案

未允许本次问题外发时，页面只做本地检索。要生成答案，请保存并启用文本生成、确认相关资料允许云端，并勾选本次问题外发。若缺少可用证据，应补充资料，而不是让模型替知识库编造依据。

关闭网页后任务还会运行吗？

本地服务仍运行时可以继续；关机、休眠或运行 stop.cmd 后不会继续。再次运行 start.cmd 会恢复服务并补算今天的安排，未完成的外部任务请检查是否需要重试。

网页打不开或提示会话过期

会话过期时先保存能保留的输入，再刷新。网页打不开时确认本机服务已经启动，访问 http://127.0.0.1:4318。若启动失败，保留启动窗口里的错误信息；不要靠删除笔记或应用数据解决。
