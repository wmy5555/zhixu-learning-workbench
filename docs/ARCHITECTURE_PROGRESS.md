## 长期业务边界

- 知识库即时筛选使用当前页面快照。全文及语义检索使用服务端索引、范围和单次外发许可。能否练习、材料是否可信与用户最终确认各用自己的证据。
- 资料成员的共享规则负责来源和稳定顺序。日常阅读按可用来源显示既有正文，结构分析和加工前仍须完整核对成员、版本与授权。历史兼容以原文可核对为准。
- 学习开始使用同一身份规则，各入口保留今日安排、主题、错题与资料的参数。会话过期只读重取、学习反馈轮询、原件上传续传、批量文本继续提交以及调用账本核对各有自己的条件与回执。
- 设置保存、测试已保存配置、用一次性回执保存已测试的草稿、按预览恢复备份是各自独立的流程。恢复凭据、调用费用、外发许可、原始回答与本人确认继续由各自的业务边界负责。
- 外部 Markdown 的识别与完整备份的校验承担不同职责。真实运行资料、独立合成预览和发布检查各用自己的证据。
