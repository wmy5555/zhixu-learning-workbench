# Android 动效与切页响应

## 本次改动

用户要求全部页面停止使用侧栏入口原有推入效果。本轮沿用已选布局，仅改动 Android 导航与页面读取时序。

| 原行为 | 新行为 | 依据 |
| --- | --- | --- |
| 侧栏先收起，再启动平台默认页面动画 | 点击条目立即撤下侧栏，只执行一次目标页原生淡入 | 避免两段串行转场和旧页回闪 |
| 页面使用系统默认位移/缩放，编辑使用模态进入 | 根 Stack 统一 fade，编辑在 Android 使用 card；返回也一致 | react-native-screens 原生 alpha 150ms，不在 JS 逐帧更新 |
| 侧栏弹簧展开，底栏标记先慢后快 | 侧栏 240ms 展开 / 180ms 收起，DECEL(.165,.84,.44,1)；标记 150ms EASE_OUT_EXPO(.16,1,.3,1) | open-claude-ui 固定 4045ce76 的 ClaudeMotionPresets.ts / cds-theme.css |
| 已访问的隐藏页面随每次 revision 重读 | 隐藏不读；未变版本暖返焦不读；失效返焦只读最新版本 | 避免隐藏页重复完整扫描，不改变原有完整性检查 |

系统减少动态效果开启时，Android 页面、侧栏和标记均直接切换。保持表单未保存保护、草稿刷新、练习空间隔离及既有外发权限。iOS 保留原导航和读取逻辑。未增加依赖，不改正式 4318。
