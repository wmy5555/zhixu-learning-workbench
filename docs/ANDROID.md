# Android 个人测试版安装与边界

本分支基于 `5e7bbd8`，已构建、临时签名并通过 `apksigner` 验证个人测试 APK。正式 Google Android SDK 协议已获用户单独批准，未接受预览条款。**跨网络直接同步尚未实现**；首版实际功能是手机本地资料库与人工文件交换。Library 文件上传是单独交付步骤，不能由构建成功推定完成。

## 数据位置与实际功能

手机工程是原生 Java App，无 WebView、GMS 或第三方运行依赖。资料保存在 App 私有目录；源码实现阅读、关键词查找、新建原文、原文编辑和系统文件选择器导入导出。学习知识、错题、主题和报告是只读副本。Android UI 与持久库已编译；设备实测范围见下文。

电脑继续保存完整 Markdown Vault、SQLite 学习与运行数据，负责学习计划、回答、AI 加工、核验与 MCP。手机并未实现这些完整功能；当前 APK 只能体验该部分功能，不能视为用户要求的直接同步已达标。手机本地阅读与收集不需要电脑开机；电脑导出、接收修改和执行完整工作台功能时须开机且服务运行。

当前只实现**人工资料文件交换，不是自动联网同步**：明确选择电脑资料导出快照，手机保存副本及待发送修改；电脑显式应用修改，再导入回执到手机。这不是远程操作同一数据库，也尚未满足用户跨不同网络直接同步的要求。

上限为 100 条、总计 8 MiB；单条标题最多 200 字、正文最多 500000 字。JSON 交换文件为明文，用户须选择可信保存位置及传递渠道。App 关闭系统自动备份，不请求存储目录常驻授权。新资料默认仅本地，不自动调用 AI；不交换密钥、供应商配置、学习回答、任务、历史、附件、Obsidian 配置或确认记录，不改变外发许可或学习资格。

## 跨网方案与待授权项

选定建议为两端通过 Tailscale 私有网络连接，可适用各自联网或热点场景，不要求同一 WiFi，直连或中继取决于 NAT。尚未安装、登录或接入；账号、第三方当前条款、地域可用性、费用与 Huawei 实机兼容性未验收。电脑只在实际同步时需运行；手机依赖该连接工具。用户未批准新的账号或常驻授权，本任务不登录、部署或操作用户防火墙。

拟新增专用资料交换桥接层，绑定明确私有网地址，绝不绑定 `0.0.0.0`、映射公网或转发任意 Web API。桥接只调用现有回环 API，设备需显式配对，交换需认证、加密、大小与重放限制。具体直接同步安全代码尚未实现；可继续做不连接真实账号、不启动外部监听的代码与本地合成模拟。实际启用专用网络入口、第三方账号与长期授权仍需单独批准。当前 Manifest **无 INTERNET 权限**且禁止明文流量，桌面适配器只接受回环 HTTP，现有 Host、Origin、CSRF 保持。

## 文件交换说明

以下是安装后的人工使用说明；本次仅针对随机临时服务和合成资料测试，未对正式库执行。交换目录保存绑定身份和回执，不含正文；不同 Vault 不能共用。目录及交换文件不能提交公共仓库。

电脑启动知序后，打开所选资料详情，在「稳定 ID」处复制 ID（多个以英文逗号分隔）：

```sh
node scripts/mobile-sync.mjs --state-dir /your/private/exchange --pull ID1,ID2 --out /your/private/to-phone.json
```

通过用户自选可信渠道传文件到手机，点击「导入电脑文件」。收集或修改原文后点击「导出手机文件」，再人工传回电脑。先做只读格式及数量预览：

```sh
node scripts/mobile-sync.mjs --state-dir /your/private/exchange --push /your/private/zhixu-phone.json --out /your/private/reply.json
```

预览不连接服务、不创建回执、不写库；审阅后显式加 `--apply`：

```sh
node scripts/mobile-sync.mjs --state-dir /your/private/exchange --push /your/private/zhixu-phone.json --out /your/private/reply.json --apply
```

再将回执 `reply.json` 导入手机。电脑后来的修改需再次 `--pull` 明确选中资料，不会主动推送。当前文件交换**不是跨网直同步交付**。

## 冲突保护

- 手机修改带最后接收的电脑哈希；复用会话、Origin、Host、CSRF 与 `expectedHash`。不启动网络监听或第二个 SQLite 写进程。
- 双方改过正文时保留手机版本并显示冲突。手机可查看电脑版本，明确采用电脑版本，或将手机版本另存为新原文后采用电脑版本；不会静默覆盖不同内容。
- 电脑删除后不重新创建。首版不传播删除，手机仍保留旧副本；文件缺席不是删除指令。
- 重发复用交换目录绑定。若电脑已写入但回执持久化中断，安全地报告重复正文冲突；不凭可被外部编辑的来源元数据猜测身份，不重复添加来源，需在电脑人工核对。
- 批量写入按条完成，不是全有全无事务。后续失败时已完成的条目保留，持久回执支持重试；输出不覆盖原手机文件。

## 安装与使用

1. 在电脑验证最终 APK SHA256 后，通过自己选择的可信方式把 APK 传到手机。用华为文件管理器打开，按 HarmonyOS 提示，仅对所用文件管理器允许安装本次外部应用。无需 Google Play 或 GMS；不修改防火墙、开启公网或连接电脑服务。系统菜单名称以实机为准，本任务没有操作真机。
2. 打开「知序 · 个人测试」，点击「收集」输入标题与原文并保存，或用「导入文本」选择 UTF-8 文本。搜索与阅读在手机进行，草稿在 App 离开前尝试保存在私有目录。不要用测试版承载唯一副本。
3. 人工电脑资料交换按上一节执行；手机不会自动发送、定时拉取或通过热点直接连接电脑。手机收集与阅读不需要电脑开机；电脑收发文件和使用完整工作台时需开机并运行知序服务。
4. 更新安装必须使用相同包名和同一临时签名。私钥仅在本任务隔离目录保留；环境丢失或签名变化后可能需卸载重装。卸载清除手机私有资料，先完成导出并核对文件；禁止自动云备份/设备迁移，不能依赖系统恢复。

## 构建与测试错误记录

- 初次最新 Command-line Tools v23 的 `sdkmanager --list_installed` 自动启动新的 Android CLI，并提示默认收集使用统计。用户未授权可选统计；该一次调用前未正确屏蔽，无法确认是否发送匿名统计，不能声称全程无遥测。发现后立即隔离 v23、改用固定 v16，不再调用该 CLI；模拟器显式 `-no-metrics`。未读取正式资料或真实密钥。
- 初次 Lint 指出缺少图标和系统备份规则；已补齐原创图标、标签资源及云备份/设备迁移排除，最终 Debug/Release Lint 均无问题。Java 编译仍有旧 API 弃用提示；使用固定 Gradle 8.13，构建输出提示未来 Gradle 9 不兼容，未升级。
- 环境无 `/dev/kvm`，模拟器使用 `-accel off -gpu swiftshader_indirect -no-metrics`。软件 CPU 不支持 AVX/F16c，启动慢并出现一次 System UI 无响应；不能用它评估真机性能。
- 模拟器未启动完成时 `adb install ...` 报 `cmd: Can't find service: package`；待 `sys.boot_completed=1` 后 `adb install --no-incremental ...` 成功。第一次 UI dump 到 `/sdcard` 后 pull 报找不到文件，改用 `/data/local/tmp` 成功。
- ADB 37 忽略指定 Android 用户目录并尝试写只读的 `/home/agent/.android`，初次服务启动失败；仅临时建立指向隔离合成测试目录的链接并使用专用 5039 端口。未读取已有设备或用户密钥；测试结束移除本任务链接和停止专用模拟器/ADB。模拟器 console token 在只读 HOME 不可创建，console 不可用；通过专用 ADB 地址完成测试。
- 后续 `pnpm check` 在默认进程沙箱首次报 `spawnSync git EPERM`，使用已授权的环境执行权限重跑后检查 154 个跟踪文件通过；不是隐藏或跳过检查。
- 软件模拟器首次打开文件选择器期间，`uiautomator dump` 曾报 `null root node`；等待系统选择器出现后，用删除旧 XML 再抓新层级的方式复验，未把旧层级当成新结果。
- 最后主动键盘输入发现只读知识的界面文字仍能暂时修改（没有保存入口且存储层拒绝写入）；修正为移除 KeyListener 并保留文本选择，新增实际 Android 字符输入回归，交付使用修正后 APK。
