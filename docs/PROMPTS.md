# 提示词设置与联系管理

系统 → 能力设置 → AI 与联网提示词，可查看及编辑实际使用的任务模板。

提供学习助手系统指令、资料拆解、学习反馈、关系分析、发现检查、主题整理、问答、核验系统指令、支持/反证搜索词和单条/批量核验模板。展开一项后可编辑，点击恢复系统默认只改编辑框，点击保存全部提示词后生效。

{{source}} 等变量由程序一次替换为当前资料；用户资料中出现的同名占位符不会再次替换。缺少必需变量、未知变量或超过30000字符的模板无法保存。搜索请求最多350字符。模型要求的JSON字段仍由业务代码验证，编辑模板不会关闭隐私、额度、来源摘录或引用校验。

修改用于后续实际请求；已有结果不会自动重做，缓存仍可复用。查看或保存模板不调用收费服务。配置保存在本地设置中并随备份保存。

已保留的关系提供查看两端知识和移除联系入口。移除解除关联并保留原笔记及历史，不自动删除任何正文；后续推荐不会再次采用已经移除的关系。
