# 知序新手引导：先核心体验，再自选扩展

## 拆解已保存与核验待补

第 9 步检查当前原文版本是否已保存真实拆解，而非等待所有联网事实核验通过。候选保存后可以阅读，核验继续运行时显示覆盖进度；证据不足的知识仍不能绕过原有学习资格要求。

在「系统 → 任务」选择“继续核验”时沿用已有拆解，优先检索此前未覆盖的内容，可能产生外部服务费用。只提高预算、刷新或查看结果不会发起请求。未发现有效反例不代表结论错误，也不等于已证明正确。

首次引导默认走 **28 步核心体验**。其余 **89 步**分为 **12 个可选扩展专题**，自行选择是否阅读或实操。原有 117 个步骤及保存的进度都保留，不必为更新重新练习。首次入门卡片、今日页和左下角帮助都可以开始或继续，文字指南仍可单独阅读。

## 选择材料

开始或确认重新练习时可选择：初中数学（维基教科书一元一次方程）、读书思考（鲁迅书摘）、工作协作（GitHub 指南）、Python 自学（官方异常教程）、数字生活（EFF 安全规划），或者自行粘贴。

选择材料时，可以展开“心得示例”和“原文摘录”预览内容，也可以通过“查看原文”打开出处。进入练习后，第一步按模块介绍首页：引导进度、快速收集、日期与今日概览、四项统计、今日安排、处理动态和今日原则；之后再带你找到各个功能的操作位置。内置材料保留作者、链接、编辑说明与许可；伴读原文和应用问题可在批量导入专题中分别下载。

自选材料填写标题、原文与可选的心得、作者、链接和位置，先本地保存在独立练习资料中。进度文件只存场景和对象身份，不存原文；收集步骤可再次检查修改并亲自保存。标题最多 200 字，与实际保存限制一致；原文 150000 字、心得 10000 字。请核对使用权限，不填密码或不愿外发的敏感信息。粘贴不会自动外发，也不会写入项目代码或公共仓库。

新场景不预建主线知识或成绩。只有在“粘贴并保存第一份资料”步骤单条保存的资料才绑定为主线；提前导入伴读或批量文件不占用主线身份。真实拆解后，在“把解释目标加入学习”选择本原文的一条实际候选，将“学习目标”设为“讲清原理”，再加入学习。其他目标为“了解用途”“会查资料”“换场景应用”，可按顺序沿用同一条非主线知识，保留各次实际操作记录；只有主线条目时提供手动整理另一项内容的入口，事实仍须核验，尚不可用就保留未完成。开始学习后主线知识固定，不以另一条知识的记录完成主线或修改其目标来补齐扩展。

数学、Python 等事实仍须满足既有核验规则。待核验或过期条目不能选入主线，提供联网加工入口；没有可学条目就保留未完成，不改类型或伪造研究成功。首次、到期变式和应用题保存在实际会话中，反馈来自模型，答案由本人提交。输出与采用须关联本原文，定位使用教程保存的草稿身份，不误打开后来的预设案例草稿。

暂停、重启和备份恢复保留场景与自选材料。旧练习继续原有虚构材料与进度，不静默替换；确认重置才换场景，只清理独立练习，保留正式库和共用配置。省略场景参数的旧 API 请求保持兼容，当前界面每次新建均明确提交选择。

## 首次体验的优先顺序

选择主线知识时，待核验提醒下的“为什么待核验的事实不能进入主线？”默认收起；鼠标悬停展开、移开收起，也可点击或用键盘 Enter/空格展开。解释说明练习和复习可能加深错误理解，须先核验并审阅来源、结论和适用范围。阅读解释不会发起联网请求或改变条目的学习资格。

AI 拆解提交后，资料详情与对应引导步骤显示转圈和排队/处理提示，处理期间不能重复提交。真实任务完成后会短暂弹出带资料标题的气泡；即使切到其他页面，当前知识库的完成通知仍会出现。打开的原始资料详情会更新拆解结果。等待条件、失败或取消时停止转圈，按提示前往「系统 → 任务」查看原因，需继续时由你主动重试。刷新页面不补弹历史完成通知；预设演示任务不作为真实 AI 完成通知。

同一份原文没有修改时，再次提交拆解会复用已有任务或结果，不重复请求拆解模型，也不增加一组相同候选。原文修改后可处理新版本。单独点击「联网核验事实与适用条件」仍会进行你主动选择的核验请求，但会复用已有拆解；人工修改过的知识继续通过修订建议保护，不会被静默覆盖。失败或取消的任务须到「系统 → 任务」手动重试，反复点击提交不会自动重发失败请求。

| 核心阶段 | 体验内容 | 步数 |
| --- | --- | --- |
| 配好 AI | 认识练习空间、填写保存配置、主动测试、阅读请求预算 | 5 |
| 收集与加工 | 保存原文、核对来源、授权示例、AI 拆解、阅读结果，把预置解释卡片加入学习 | 6 |
| 学习并确认理解 | 分别授权原文和知识、安排学习、隐藏材料作答、查看反馈、结束练习、亲自确认 | 9 |
| 体验到期复习 | 跳到下次复习，亲手完成一次到期练习 | 2 |
| 检索与输出 | 关键词查找、生成草稿、核对引用、编辑、确认实际采用 | 5 |
| 回顾核心体验 | 核对核心记录后回正式库，或自选扩展阅读 | 1 |

“下一步”和阅读后的自动前进只沿当前路线移动。核心路线不会自动进入扩展专题；扩展专题结束后可返回核心流程，也可以自己挑选另一个专题。核心完成只核对这 28 步，扩展步骤未完成或待配置不会阻止完成。仅翻到最后一步不会标记完成；“继续核心流程”会回到首个未完成步骤。

扩展阅读包含学习偏好与保存位置、批量文件导入、手工整理与联网核验、知识管理进阶、学习安排与多轮练习、复习进阶与提示案例、错题与争议、主题学习、语义检索与联系发现、更多输出方式与阶段建议、维护与备份、外部工具与文件协作。第一次进入时目录收起，用户自己展开并选择。建议先完成核心体验，扩展实操会复用已经保存的示例；若有额外前置操作，按当前步骤说明补做即可。

## 怎样开始

1. 点击“开始新手引导”，选择材料并查看原文预览，确认后进入独立练习空间。
2. 在第一章进入正式能力设置，填写服务地址、模型和密钥，保存后主动点击测试连接。已有配置可以直接测试。
3. 连接成功后，跟着每步提示操作真实界面。示例输入按钮只帮你填写，不会替你提交；回答和个人理解由你自己写。
4. 等待真实任务成功后检查本步；先走完核心，暂未配置的扩展能力可保留待体验。
5. 可以暂停并退出，之后继续。重新练习会重置这个练习空间。

阅读说明后点击“我已阅读”，保存成功会自动进入当前路线的下一步；处于路线最后一步则停留供你选择。保存失败时留在当前步骤并显示原因，可以再次点击重试；实操步骤仍依据实际结果确认，不会因导航而完成。

实操点击“检查这一步”后，找到完成记录会弹出“检查已通过”提示，当前步骤仍保持可见，按钮改为“进行下一步”，由你点击后继续。已完成步骤刷新或续学时直接显示前进入口，不反复弹出通知；记录不再满足条件时恢复检查。未通过或请求失败会显示原因并保留重试入口；后台任务随后完成时，本步旧的检查失败提示会自动清除。演示案例提示明确写明演示记录；外部体验只确认你的记录，不代表系统验证连接成功。专题最后一步提供返回核心流程入口，不自动进入另一个扩展专题。

点击“定位操作位置”，对应控件会滚动到视野中，边框短暂闪烁三次后保持高亮；重复点击可再次提示。系统开启“减少动态效果”时只显示静态高亮。

核心第七步会框选“查看原始资料全文”的展开区域，点击后阅读原文；再展开“原始资料信息”核对来源。

定位会打开相应的草稿、资料或学习会话，并优先框选隐私选项、作答区、反馈、引用采用项等具体控件。边框画在控件内侧，抽屉和滚动区域不会裁掉外框；已关闭的抽屉及被抽屉遮住的页面不参与定位。折叠区域会自动展开。

尚未保存资料、开始学习、生成输出或准备案例时，会说明缺少哪一步，并框选可继续的入口。复习日期直接框选引导中的时间按钮；这些按钮位于引导窗内，窄屏定位后保留展开。定位不会替你提交回答、生成输出、准备案例或推进时间。扩展教程的搜索、语义和 MCP 配置会明确进入正式能力设置，供练习库共用。

窗口宽度不超过 1100 像素时，引导显示为右下角浮窗，说明在窗内滚动，标题和收起按钮一直可见。点击“收成小窗”可只保留当前步骤；点击“展开步骤”继续阅读。在浮窗内按 Esc 也可收起。成功定位到操作控件后会自动收成小窗，为页面操作让出空间；找不到目标或操作失败时保留说明。打开资料详情时浮窗仍固定在屏幕右下角。收起、展开和调整窗口大小都不会改变学习进度，宽屏仍使用右侧引导栏。

## 数据、时间和进度意味着什么

旧教程的生成点击只有同时保留主线已完成的实际安排、或由该安排开始的实际会话，才保留此前完成状态；空点击和其他知识的安排不能代替主线。前置知识阻塞时，“未安排的原因”提供具体前置入口；已停用和已被替代的知识分别解释，不引导重新加工来改变其学习状态。

前置知识因预算不足没有安排时，后续知识也会指出具体前置，可先查看该项原因或调整预算。多来源知识的重新加工入口对应实际拆解原文；该原文已删除或来源不明确时，不会用另一份资料代替。旧知识未记录学习目标时，编辑页和练习均按“讲清原理”显示与安排，保存未修改的目标不会改写版本。

核心第14步“生成今日清单”需要选中的解释知识实际出现为今日待学项。选择主线、设置“讲清原理”和允许云端都不会自动加入学习；若主线仍为待选学，点击引导中的“回到加入学习这一步”，打开知识详情，点击“加入学习”并填写理由，再回今日生成。清单为空或缺少该项时，展开“未安排的原因”，按学习状态、核验、暂停、未到期或预算提示处理；可直接查看知识、原文或调整预算。

保存没有修改的编辑表单会显示“内容未改变，已确认当前设置”，不会新增版本。若旧练习已经显示“底层原始资料已修改或删除，需要重新加工”，更新程序不会自动恢复旧知识的资格：由本人从“查看原文并重新加工”打开原文，主动加工并审阅结果，回到“把解释目标加入学习”选择当前有效候选、加入学习，再生成清单。需要模型或联网的加工仍可能计费，事实仍须满足核验条件；不要通过更改类型或自动补任务绕过。

- 标题的“当前第几步”表示正在查看的核心路线或扩展专题中的位置；“核心完成进度”单独统计核心实操与阅读。扩展专题另有自己的完成数。返回前面的步骤只改变当前位置，不会清除完成进度。
- 练习中的文件、索引、任务、历史和备份独立保存。新场景主线只使用实际拆解知识；旧练习的四张候选卡片继续保留，没有预设成绩。正式库和练习库的 AI 凭据与预算共用，配置变更后需要重新测试。
- 本地资料默认不外发。示例原文和知识需分别由你允许云端处理；知识不能越过其来源的本地限制。
- “已实操”表示对应操作已有结果；“已看案例”表示使用了明确标识的预设数据；“待配置”和“未完成”保留尚未做完的事项。加载案例或只点击下一步都不会成为真实成功证据。
- 时间加速只改变练习的学习日期。收到明确反馈并结束练习后才会结算复习；争议反馈只保留记录，不创建或更新复习安排。“跳到下次复习”若发现没有安排，会带回“开始解释示例”并说明原因；复习步骤也提供“重新练习这条知识”入口。由你核对材料、提交新回答并结束后再继续，导航不会自动调用 AI 或制造完成记录。
- 日期推进不会新增正确回答或掌握证据；电脑时间、正式库、网络等待和请求预算继续使用真实时间。
- AI 失败时输入仍保留，重试由你决定；预设内容不是实际供应商返回。外部客户端的人工确认只能记录体验，不能证明真实接通。
- 已提交回答需要先处理反馈并结束本轮，才能推进日期。若材料已修改或决定不再继续，可在引导的练习时间区域选择“结束未完成练习”：保留原回答和已有反馈，不产生学习成绩，也不调整复习间隔。
- 练习备份有用途标识，不能恢复进正式库；JSON 备份不包含图片附件和 Obsidian 配置，需要另外保存整个 Vault。
- 诊断中的调用次数和调用表来自共用的 AI 服务，包含正式与练习请求，只读展示，不写入练习备份。教程不保存密钥。
- 备份携带示例对象的身份映射，恢复后可以继续定位对应条目；完成进度仍独立核对。恢复会重建关键词索引，语义向量需要你主动补建。
- “外部工具与文件协作”扩展专题单独显示外部体验状态：MCP 以已有服务调用记录标明最近观察时间；Obsidian 以你的实际体验确认记录，人工确认不会变成系统验证成功。核心完成页不要求连接这些工具。

## 预设案例清单

仅在点击加载时准备案例，重复点击不会重复创建，合并或删除后的对象也不会自动复活。案例的文件和运行记录都带预设标记。

| 案例 | 用途 | 与主线的关系 |
| --- | --- | --- |
| 提示完成、错题 | 查看提示后的安排、专用项跳过与暂停、错误与争议处理 | 专用知识、会话和错题，不修改主线成绩 |
| 历史、重复与删除 | 历史查看与恢复、合并预览、确认、删除 | 每类操作使用专用卡片，保留主线的学习阶段与权限 |
| 前置阻塞 | 展示前置事实待核验的阻塞原因 | 待核验限制真实保留 |
| 证据展示、资料过期 | 支持、反对、限制与复查提醒 | 虚构依据不能成为事实核验成功 |
| 关系审阅 | 接受、拒绝、忽略、移除 | 专用关系和知识对 |
| 核心建议 | 观察跨日练习与采用的建议依据，接受与暂不采纳 | 预设记录始终与自己的学习区别显示 |
| 写入提案 | 对比前后，接受或拒绝 | 不开启正式 MCP 权限 |
| 任务故障 | 取消、手动重试 | 预设重试只进行本地扫描 |

## 验收边界

自动测试使用随机临时目录和离线受控数据，不读取真实资料或凭据。应分别记录自动测试结果、真实浏览器走查结果、用户主动进行的供应商测试以及外部客户端调用记录；其中一种结果不能代替另一种。

本文件没有宣称真实模型、搜索、向量服务、MCP 客户端或 Obsidian 已经成功验收。具体通过项与未验证项以对应交付记录为准。
