# 自动公开模型价格

## 使用方式

「系统 → 用量与费用」自动展示当前文本模型、嵌入模型的价格来源及覆盖状态。正式网页服务启动后在后台获取固定的 `https://models.dev/api.json`，成功版本每 24 小时更新一次；页面有手动更新按钮。失败保留上次成功目录，显示过期/失败状态，自动失败重试间隔至少 1 小时；连续手动更新至少相隔 1 分钟。关闭自动更新后不再发起新的目录请求，保留已有缓存和手动价。

目录请求只发送固定 URL 和 JSON Accept 头，不携带供应商密钥、模型配置、笔记、查询词、Cookie 或 Referrer。不跟随重定向，不访问目录提供的任意链接；最长 10 秒，解码后的响应至多 16 MiB。获取时间不是供应商价格的生效日期；目录是社区维护的公开估算来源，不保证与实时账单一致。

- 只匹配精确的供应商、完整服务基础地址、模型 ID 和标准计费方式。地址仅规范化 URL 与末尾斜线，不移除任意路径、不把代理域名当官方域名、不根据模型别名或 canonical ID 套价。不同渠道的同名模型分别统计。
- 上游 OpenAI 记录没有 API 字段，只为该供应商补充 SDK 官方默认 `https://api.openai.com/v1`；其他无法核实的地址不猜。多个供应商条目匹配时保留未知。目录内缺失或无法匹配的服务，可手动填价。
- 任何已填写的手动单价（包括明确的 0）优先于整组公开价格，刷新不会覆盖它。部分手动价不会与公开价格拼接。清空该模型全部手动单价，恢复自动匹配；手动模式显式开启时仍保留未知。
- 新手动价可填写币种，例如 USD、CNY。旧记录保留原金额，标记 `legacy_manual` / 币种未确认；不推断旧币种，也不回写历史。
- 公开价格单位为 **USD / 百万 token**。搜索仍为独立的手动每次请求价格；网页读取沿用本机直接读取费用为 0 的现有口径，不套模型价。

## 支持与未知

支持标准文本的输入/输出价格、嵌入输入价格，以及现有 OpenAI-compatible/DeepSeek 响应中的缓存命中输入细分。缓存输入属于输入总数，推理 token 属于输出总数，不重复累计。显式缓存折扣需要实际报告缓存数量，否则费用未知。

上下文阶梯、缓存写入与 TTL、不同推理单价、特殊服务模式、batch/priority/flex 计费等没有完整支持；相关公开条目显示部分覆盖，费用为 `null`，不能当作免费。只有公开或手动价格明确为 0，且必要用量完整，才计作零费用。文本请求不采用音频价格；不提供多模态计费。

超过 24 小时的目录仅在未启用金额预算时继续提供带过期标记的估算。启用正数月预算时，当前过期自动报价及本月已按过期自动价生成的历史估算都会阻止新请求，不据此计算可信余额。新鲜目录和手动单价不受目录过期限制，但不会追溯改写本月已有的不可信估算。对于已记账的过期估算，页面提供「过期估算待核对」入口：用户核对供应商账单后填写实际金额、币种和说明，保存独立核对记录；预算使用该核对金额，原始估算、价格快照与已收响应均保持不变。未知结果调用沿用原有费用确认入口，确认后的金额同样可用于预算，不再仅因原快照过期而阻断。核对不会重新发送调用；当前新请求仍需新鲜目录或可用手动价。旧 legacy 手动行为保持不变。不可用、缺失或不支持的价格继续未知。真实费用以供应商结算为准，系统不主动调用供应商来核对账单。

## 历史与预算

每次请求在持久预留前选择不可变 `pricingSnapshot`，保存供应商、渠道摘要、模型、计费模式、币种、实际采用单价、来源、目录 SHA-256、获取时间、选择时间和覆盖状态。预留、响应及账本保留同一份快照。目录刷新、配置更改、迟到响应、补记、重启和响应复用均不按新价重算旧调用。

统计分币种汇总；USD、CNY 和旧币种未确认金额不会相加。混合币种时总额显示分列，费用趋势不绘制一个合计金额，Token/请求趋势仍可查看。旧记录只按既有手动单位展示，不能据此声称其是人民币或美元。

正数月预算需与新请求及本月非零费用的币种一致。未匹配/部分覆盖的新请求、本月未知费用或币种冲突都会阻止新请求。旧纯手动配置及旧无币种预算保留原兼容行为；引入 USD 目录价后，需要明确选择 USD 预算币种，本月旧币种未确认记录不会被自动转换。跨币种预算整合及旧历史币种确认迁移尚未提供，可在预算关闭时独立查看不同币种估算；关闭预算不会解除未知调用的恢复保护。预算仍是按已记账费用的前置保护，单次生成实际费用可能超过余额。

## 缓存与验证

目录保存在应用数据目录的可再生成缓存文件中，完整候选通过结构、身份、有限非负单价和大小校验后才原子替换。失败不覆盖上次版本。公开目录缓存不放进学习备份；调用本身的价格快照随账本备份保留，恢复仍优先保留本机调用证据。没有新增依赖，不改项目许可证。

主要模块：`src/price-catalog.mjs`（固定来源、缓存与刷新）、`src/pricing.mjs`（精确身份、快照与币种）、原有 AI/账本/报表集成。`POST /api/usage/pricing-refresh` 复用现有会话和 CSRF；练习空间只读正式库的目录与统计，不能刷新或修改设置。

测试只使用随机临时目录、合成目录和模拟外部响应，覆盖匹配/代理/别名、缓存与推理去重、手动优先、未知/过期、限量限时、原子失败保留、预算币种和中断恢复。真实供应商价格、付费请求、生产配置和账单没有验收。
