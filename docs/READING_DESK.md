# 阅读书桌

阅读正文呈现知识内容。ChatGPT 会话保存模板中的摘要、范围和结构化数据不再与原文混排；书桌概览包含摘要预览、完整摘要展开和收集范围。原文记录与完整性证据不修改，不执行数据迁移。

读取既有保存模板时只移除可识别的外层传输围栏和字段，保留消息实际内容和其内部代码块。无法识别的人工编辑保留显示，不用快照静默替换。已识别的导出布局标记转为普通文字；图表 JSON 仅用 JSON.parse 转成数据表，引用组件保留真实链接、隐藏私有 token；不执行组件、脚本、事件或加载远程资产。

目录优先采用当前 ready/partial 整理结构的短标题和经原文核对的来源位置，按原文顺序排列。旧资料与无有效结构的资料使用实际正文标题；stale 结构不用于导航。整理提示要求逐段阅读、语义归组并提供来源引用，同次已有整理调用完成，不追加调用。旧 v1 资料不会在打开时被自动重新分析；本轮未调用真实 AI 供应商。

“从这份资料拆解”使用真实 source.children；“其他关联知识”使用来源及子知识的已接受关系，排除自身、重复项、已停用和被替代的知识。两组各先显示五条，原生展开控件展示余项。窄屏保留可滚动的书桌区域；专注阅读仍能收起侧栏。

桌面阅读右栏保留“这份资料里的想法”完整编号列表，使用同一份来源子知识，逐条显示标题和学习阶段，并可直接打开阅读。该列表与左侧分组同时保留，不因新增整理操作或展开更多而移除；窄屏和专注阅读仍沿用现有侧栏收起规则。

ChatGPT 插件发布为 1.0.4。新规则约束内容字段和 v2 目录生成，不新增 schema 字段，不改变 App 绑定、受众、权限或保存校验。已读回发布后的 manifest 和 Skill；真实 ChatGPT 会话经新版规则重新保存仍属独立验收，未为测试写入真实知识库。

本次回归：reading-content 的合成用例覆盖传输字段分离、嵌套代码保留、人工内容保护、有效及失效定位、来源/关系分组、导出图表与引用安全呈现；prompts 与 prompt-settings 用例覆盖整理提示进入已有请求及自定义模板边界。实页只读验收使用用户批注的既有资料，未读取 Vault 文件、调用 AI 或更改原资料。正式同步的源码、进程、资源哈希和回退依据保存在本机正式启动目录，不提交真实资料或截图。

正式同步发现旧启动脚本只认 app.mjs，而当前首页使用 web/main.mjs，造成服务已启动但就绪探测超时。同步过程先恢复原版服务，随后扩展探测兼容两种既有入口；不改端口、权限、凭据或数据路径。正式启动与桌面快捷方式重开用实际进程和资源验证，不以脚本退出或 HTTP 200 单独作为成功证据。

单星号包裹的行内文字（如 `*强调*`）在阅读书桌显示为斜体，与可视化正文编辑器保存的格式对应。仅呈现格式，不改写存储原文；代码、反斜杠转义、来源链接与 HTML/协议安全限制保持。此局部修复不扩展为完整 Markdown 语法支持。
