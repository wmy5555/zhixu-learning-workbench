# 需求—实现—验收对照

## 尚不能宣告最终完整验收的项目

1. 真实模型单次合成整理的既有记录见 [AI 整理失败修复](FIX_2026-09-20_PROCESSING.md)；它不等于真实混合材料研究→AI 学习批改→同义检索→有据输出的在线闭环。当前供应商配置未作为本次源码审阅的证据来源，不能照旧文断言从未配置。
2. 质量材料以小型固定集和受控接口响应为主，新增学习、存储和 UI 回归用于发现程序与权限退化。跨域关联价值、事实争议判断、同义召回、批改合理性仍需真实模型结果并人工审阅。联网批处理仍是有限网页、有限预算的证据调查，不承诺全面核验。
3. 只提供本地部署和本地 stdio MCP；未接入用户日常使用的第三方桌面客户端界面，官方 SDK 兼容客户端已实测。未提供公网访问、多用户、手机同步、视频转录或 OCR。
4. 外部 Vault 附件和 Obsidian 设置不在文本 JSON 备份中；长期运行、大库性能和恢复中断的断电场景尚未作持续性实机试验。

本轮回归入口包括 `tests/learning-alignment.test.mjs`、`tests/store-alignment.test.mjs` 和 `tests/ui-alignment.test.mjs`；UI 测试实际触发按钮与表单事件，但不替代浏览器视觉验收。完整运行数量与在线边界应以本次验收报告为准，不把旧的测试总数累加。

这些是保留的验收缺口与范围说明，不视为施工计划已全部完成。真实供应商和用户材料的后续验收仍需用户主动选择执行，并记录实际成功、失败、调用量及费用未知的情况。
