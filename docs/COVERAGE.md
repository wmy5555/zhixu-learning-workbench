# 需求—实现—验收对照

依据用户提供的 2026-09-20 施工计划 v1。这里区分功能实现、离线编排测试和真实外部能力验收。

| 需求 | 实现位置 | 已有证据 / 剩余边界 |
|---|---|---|
| 中文单窗口、原文输入、批量文本导入 | public/app.mjs、service.importItems | 浏览器粘贴保存实测；原文与来源持久化测试 |
| 三层数据、稳定身份、未知属性保留 | store.mjs、service.confirmNote | 外改/改名/未知属性/哈希冲突测试 |
| 真实拆解、事实/观点、搜索+读正文、反证 | ai.research、service.processSource | 请求结构与证据引用隔离测试；尚无真实模型/搜索凭据，不认定线上通过 |
| 失败、预算、重试、取消、原始快照 | ai.mjs、service.runJobs | 缺密钥、仅本地、预算、超时/取消测试；网页研究失败保留候选和原因 |
| 参考/候选/学习/整合/核心、可读理由 | service.promote/confirmNote/merge、知识抽屉 | 不允许 AI 自行确认掌握；合并保留两份观点和来源；语义去重仍以人工合并为主 |
| 主题包、前置缺口、用户调整 | service.suggestTopics/createTopic、主题页 | 有界摘要形成建议报告，手工选择/排序/合并/拆分主题；AI 建议质量待真实接口验收 |
| 主动回忆、提示、逐轮追问与反馈 | service.startStudy/answerStudy/grade、学习页 | 原答和提示留存，离线答案重启保存；真实教学质量待验收 |
| 错题修正、质疑、撤销、重复历史 | service.mistakeAction/grade | 错误原答不进默认检索；精确误解摘要去重，近义误解归并仍需增强 |
| 今日预算、延期、暂停、持久调度 | service.today/tick、server调度器 | 时间预算、重复触发、重启状态测试；服务需持续运行 |
| 中文关键词、向量与混合检索、分层取材 | service.search/rebuildIndex | 中文精确查找和隔离测试；向量需配置嵌入并重建，真实同义质量待验收 |
| 局部候选、跨域桥梁、周期结构报告 | service.relate/discover | 有限关键词候选与跨主题候选、依据/用途/边界、接受拒绝；真实关联质量待验收 |
| 问答、引用、素材/提纲/草稿、实际采用 | service.ask/updateDraft、输出页 | 引用 id 与正文一致性检查，草稿隔离；真实回答语义支持性待验收 |
| 独立可替换API、密钥、成本 | ai.mjs、secrets.mjs、系统页 | DPAPI与脱敏测试；兼容chat completions / embeddings / Tavily；供应商差异需连接测试 |

| 技术学习、检索/MCP诊断 | 系统页技术说明、service.diagnostics | 提供片段数、关键词/向量命中、MCP操作与返回数；无需隐藏推理 |
| 备份恢复、历史、删除、索引重建 | store.backup/restore/history、系统页 | 开放JSON恢复学习记录；附件和.obsidian需整目录另备份 |
| 注入、越权、仅本地、跨站访问 | ai地址防护、server鉴权、安全DOM | Host/Origin/CSRF/令牌/私网/查询隐私/注入文本数据化测试 |

## 尚不能宣告最终完整验收的项目

1. 没有真实模型、搜索、嵌入 API 凭据，未完成真实混合材料研究→AI 学习批改→同义检索→有据输出的在线闭环。模拟编排和接口实现不能替代该验收。
2. 质量材料目前是小型固定集，覆盖中文精确查找、错误隔离、引用拒绝等。跨域关联价值、事实争议判断和批改合理性需要真实模型结果并人工审阅。
3. 只提供本地部署和本地 stdio MCP；未接入用户日常使用的第三方桌面客户端界面，官方 SDK 兼容客户端已实测。未提供公网访问、多用户、手机同步、视频转录或 OCR。
4. 外部 Vault 附件和 Obsidian 设置不在文本 JSON 备份中；长期运行、大库性能和恢复中断的断电场景尚未作持续性实机试验。

这些是保留的验收缺口与范围说明，不视为施工计划已全部完成。补充凭据后，可直接在 Web 配置和运行真实材料继续验收。
