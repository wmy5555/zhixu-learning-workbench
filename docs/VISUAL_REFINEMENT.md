# 知序视觉优化候选

本候选基于 `fed3e956`，只用于独立预览，尚未部署到正式 4318。页面使用原生前端与现有接口，没有改动资料、学习条件、权限或模型行为。

| 位置 | 调整前 | 调整后 |
| --- | --- | --- |
| 公共导航 | 植物标识、英文小字、重复收集入口和格言 | 原创书页边线标识，保留一组完整导航 |
| 首页标题 | 英文眉题与多组鼓励语 | 只保留“让思考，有迹可循。” |
| 首页主区 | 浅橙装饰卡和植物插画 | 展示待学题目或最近资料的标题、正文与一个主要动作 |
| 首页安排 | 空安排大区、首个学习项重复出现 | 紧凑安排区，首项只出现一次，保留稍后和更多操作 |
| 首页辅助区 | 预算、双入口、格言并列 | 时间与真实资料数量，近期内容上移；番茄钟及预算调整保留 |
| 知识库控制 | 分类、搜索、筛选分层占位 | 一条工具栏，展开后保留全部类别、状态与分组功能 |
| 知识库内容 | 固定高度网格卡片 | 全宽资料条目、正文摘录与来源边线，取消悬浮位移 |
| 知识库稀疏状态 | 无子知识也出现分组层、无建议仍有空面板 | 无子知识按普通条目展示，无建议时隐藏面板 |
| 阅读标题 | 重复书桌标题与英文眉题 | 来源边线与正文标题，保留字数、状态、阅读时间 |
| 阅读两侧 | 固定三栏、空目录和空关联区 | 有实际目录、摘要或关联内容才占栏；知识不重复列两次 |
| 阅读动作 | 强调色 AI 按钮与泛化格言 | 原文末尾的次要 AI 操作及手工整理；学习和来源核对入口保留 |

## 独立预览

安装锁定依赖后执行 `node scripts/visual-preview.mjs`。4357 为一份资料的稀疏状态，4359 为两份资料和两条知识的状态。两者只绑定回环地址，启动时创建随机临时库；调度器关闭，不复用真实配置，不自动调用 AI。停止该进程即可停止预览；不要用正式服务的启动或停止脚本管理它。

若需旧版对照，先将 `fed3e956` 的 `src/`、`public/` 与 `package.json` 导出至 `.tmp/baseline/`，再执行 `node scripts/visual-preview.mjs --before`，对应端口为 4356、4358。截图只使用这些合成资料，不包含个人库。

## 验证与边界

- 新增回归覆盖空栏收起、目录及关联栏出现、子知识去重、AI/手工动作保留、标题转义，以及首页空库/有资料/有安排三种主要动作。
- 既有阅读内容、学习动作、阅读返回测试已执行。三项旧布局断言按本次设计更新，保留完整子知识、出处、摘要、学习条件和操作的行为断言；首次失败不计为通过。
- 浏览器验证搜索、类型筛选、无结果、按原文分组、阅读返回保留筛选、目录定位、专注阅读。完整截图和本轮检查回执保存在本地交付目录，不作为真实用户库或供应商验收。
- 没有新增依赖、字体、外部图片、后台计时器或业务网络请求。新增本地样式表 9,912 字节（gzip 2,298 字节），这是文件大小，不是响应时间测量；主页摘录只处理已有的最近四条资料。长库性能、真实 AI、实体移动设备与全产品回归未验收。
- 本次不新建即时 PR，不合并，不部署。未选定预览不得自动纳入日批产品发布；正式采用时仍需对应候选的 CI 与按需代码审查。

## 实现注意事项

阅读详情在初始正文之后增量加载。侧栏的 `hidden` 属性必须随详情更新，同时保留原滚动容器、焦点、选区与展开状态。专注模式的单栏规则须覆盖条件三栏规则，不能仅隐藏侧栏而留下空网格轨道。

前后截图应使用同一份资料、主题、筛选状态与视口；确认页面入场动画结束后采集。截图失败或只截到可见区域时，不能将其称为完整长页面。
