# Android 与网页版共用界面

2026-10-07，第一批 Android 样机的范围与后续实施约定。

知序 Android 版沿用网页版的页面、样式和交互源码。本批先接通“新建原文 → 本机保存 → 列表搜索 → 查看与编辑”，为后续迁移学习功能建立基础。这是有限功能样机，不代表手机版已经具备网页版全部能力；APK 构建、安装和真机操作仍需各自取得验证证据。

## 为什么以后可以一起重构外观

Android 工程位于 `apps/android/`，采用固定版本 Capacitor 8.5.2，将 `public/` 的网页资源打包到 App。页面实际使用同一份 `public/index.html`、`public/app.mjs`、`public/styles.css`、`public/ui.mjs`，不另建一套外观相似但独立维护的手机页面。

后续调整配色、字号、间距、按钮、卡片或页面结构时，应修改共用源码，并同时检查电脑宽屏和手机窄屏。手机需要的安全区、触控尺寸、键盘避让和返回操作，在共用页面中按设备能力适配；启动画面、系统状态栏等原生部分则由 Android 工程管理。

| 改动 | 两端更新方式 |
|---|---|
| 颜色、字体、圆角、间距、阴影 | 修改共用样式；保持集中定义，避免在手机工程复制一套设计值 |
| 卡片、按钮、表单、详情抽屉 | 修改共用组件与渲染逻辑；检查触控与鼠标操作 |
| 页面结构和导航 | 共用页面内容，按屏幕尺寸调整布局 |
| 状态栏、启动画面、系统返回键 | 调整 Android 专用能力，并核对与网页交互的衔接 |

**共用源码不等于已安装的 App 自动更新。** 网页资源修改后，手机发布仍需重新同步资源、构建并分发新版安装包。样机不提供在线热更新，也不从电脑服务实时加载页面。

## 功能对照清单

表中的“本批支持”指实现范围，不代替设备验收结论。“后续接入”功能不得返回伪造成功、预设学习结果或虚构 AI 记录；相关操作必须禁用并说明原因。

| 网页功能 | Android 本批范围 | 后续阶段 |
|---|---|---|
| 收集与加工：输入标题、粘贴原文 | 支持原文创建，保存于手机本机 | 完善来源信息与采集入口 |
| 收集与加工：文件导入、AI 拆解、联网核验 | 未实现，操作禁用 | 文件接入、AI 与研究阶段 |
| 知识库：原文列表、搜索、查看、编辑 | 支持；只覆盖手机样机创建的原文 | 扩展知识类型、来源关系、版本与结构图 |
| 知识库：删除、合并、提取、晋级、确认理解 | 未实现，操作禁用 | 数据迁移与学习规则阶段 |
| 今日：计划、延期、暂停、到期复习 | 未实现，不生成模拟计划 | 手机本地学习闭环 |
| 学习与错题：作答、反馈、结算、复习 | 未实现，不生成模拟掌握记录 | 手机本地学习闭环与 AI 阶段 |
| 主题学习包：成员、顺序、前置条件 | 未实现 | 手机本地学习闭环 |
| 检索与发现：原文列表中的本地文字搜索 | 支持列表内搜索；不等于完整检索模块 | 扩展过滤与检索质量验收 |
| 检索与发现：语义检索、关联建议与证据 | 未实现 | 向量与研究阶段 |
| 问答与输出：引用、提纲、草稿及回流 | 未实现 | AI 与输出阶段 |
| 系统：模型、搜索、向量、费用与凭据 | 未实现，不连接供应商 | 权限、凭据与预算接入 |
| 系统：导入导出、完整备份、恢复 | 未实现；当前不能用于迁移正式资料 | 数据可迁移阶段 |
| 新手实操、独立练习库及练习时间 | 未实现，不把正式手机资料当练习库 | 学习与引导阶段 |
| 双端同步、通知、后台任务 | 未实现 | 分别实现与验收 |
| MCP、ChatGPT 隧道、Obsidian 文件夹 | 未实现手机接入；电脑能力不自动延伸到手机 | 按实际需求单独设计 |

本批不要求电脑在线，也不改为访问电脑局域网服务。页面能打开与手机断网保存成功是两项不同的验收内容。

## 数据和能力边界

手机原文以本机 Markdown 文件为权威，SQLite 仅保存可从这些文件重建的索引。列表与搜索需要的派生数据损坏或丢失时，应能由有效 Markdown 重新建立；不能将索引中的旧内容反向覆盖原文。

这里的“SQLite 可重建”仅适用于本批原文样机。未来学习回答、任务检查点、历史与费用记录是独立的持久化资料，不能因为它们也存入 SQLite 就视作可丢弃索引。接入这些功能前，需要明确保存、备份、恢复和迁移规则。

本批资料保存在应用私有空间，不读电脑的正式 Vault、数据库、备份或凭据，不配置模型、不外发资料。清除应用数据或卸载可能丢失样机资料；由于导出与完整备份尚未接入，验收只使用可丢弃的合成原文。

实现和后续验收应遵守以下规则：

- 原文拥有稳定身份和内容版本；旧页面的保存不能静默覆盖较新的修改。
- 写入中断后保留可解释的状态；正文保存与索引更新出现分歧时，以有效 Markdown 为准恢复索引。
- 未支持的操作在界面禁用，设备接口同样拒绝，不能只靠按钮外观限制。
- 原文、用户回答、AI 建议与最终确认仍是不同记录，不能在适配时合并含义。
- 不以样机需要为由放宽网页版的会话、CSRF、外发权限或预算规则。

## 共用代码的分层方向

| 层次 | 职责 | 当前与后续处理 |
|---|---|---|
| 共用界面 | 页面、样式、组件、表单依赖、错误与空状态 | 继续以 `public/` 为唯一维护源；通过能力说明控制可用入口 |
| 请求接入 | 页面请求、错误约定、上下文与设备分派 | 在现有 `public/api.mjs` 接入设备能力；电脑继续使用现有本地 HTTP 服务 |
| 共用业务规则 | 学习阶段、结算、任务状态、外发与预算规则 | 后续从现有业务模块逐项抽离；本批不复制一套简化学习规则 |
| 设备存储与系统能力 | Markdown、SQLite、凭据、文件选择、通知和后台调度 | 电脑和 Android 分别实现，遵守同一业务约定 |

Capacitor 负责网页与 Android 能力之间的调用，不会直接运行现有 Node.js 后端。`src/store.mjs` 的 Node 文件系统和原生 SQLite、`src/service.mjs` 的编排，仍需要按模块迁移。接口外形相同也不代表已经实现全部业务语义。

原有练习库切换、请求进行中保护、过期响应拒绝与错误信息，应保留在共用请求层；手机尚未支持的练习能力保持关闭。未来支持学习、AI 或后台任务时，再扩展设备能力，避免页面代码依赖某一个平台的数据库实现。

## 分期交付与完成标准

| 阶段 | 交付范围 | 完成标准 |
|---|---|---|
| 1．共用界面与原文本地样机 | 共用网页资源、Android 工程、原文保存/搜索/查看/编辑、Markdown 与索引 | 工程可构建；设备断网完成原文闭环；退出重开仍可读取；清除测试索引后能重建；未支持操作明确禁用 |
| 2．数据可迁移与恢复 | 来源信息、文件接入、版本、备份导出与恢复、升级迁移 | 使用临时资料完成导入导出和恢复；冲突与中断不会静默丢数据 |
| 3．手机本地学习闭环 | 今日、作答、结算、错题、主题、练习库与引导 | 电脑关机且手机断网时保存学习记录；同一练习不会重复结算；正式库与练习库隔离 |
| 4．AI、研究与输出 | 凭据保护、外发授权、预算、任务检查点、真实供应商调用 | 经明确授权用合成资料验收真实调用；中断可恢复；不盲目重发可能已计费的请求 |
| 5．双端同步与手机系统能力 | 配对、增量与删除记录、冲突处理、通知、后台调度 | 离线后重连保留双方修改；费用与学习事件不重复计算；系统中断后状态可解释 |
| 6．发布打磨 | 正式签名、安装升级、设备兼容、无障碍与恢复说明 | 正式安装包可安装并覆盖升级；资料保留；发布说明与实际能力一致 |

阶段 5 的同步传输和手机系统能力可以分别交付。同步前先确定是否需要云端中转、哪些资料离开设备和相应授权；不直接通过网盘同步正在运行的 SQLite 文件。

每个阶段都保留共用界面原则。视觉重构可以独立进行，不要求先完成全部 Android 业务迁移；但发布时必须同时检查宽屏与手机布局。

## 验证如何记录

| 证据 | 能证明什么 | 不能代替什么 |
|---|---|---|
| 网页与接口回归、`pnpm verify` | 共用代码、既有电脑行为和已覆盖的接口约定 | Android 编译、原生文件系统与设备行为 |
| 原生桥的受控测试 | 参数处理、失败分支和指定存储规则 | WebView 实际调用、系统结束进程后的恢复 |
| Android 构建成功 | 指定工具链能够生成安装包 | 安装、显示、断网持久化与真机可用性 |
| 模拟器操作 | 对应 Android 环境中的已执行路径 | 所有手机型号、真实设备与供应商调用 |
| 真机验收 | 指定设备和版本上的实际行为 | 未覆盖设备、系统版本或未来更新 |
| 真实供应商验收 | 特定配置与授权下的实际外部请求 | 所有供应商、用户真实资料质量或长期稳定性 |

第一批需要优先验证：断网创建原文、搜索与编辑、退出重开、旧版本保存冲突、索引重建、不可用入口，以及窄屏下键盘和详情抽屉的操作。全部使用独立合成资料，不读取正式知识库。

本文件定义范围与验收标准，不登记未执行的成功结果。实际命令、提交、设备与未完成项由相应交付记录说明；没有 APK 或真机证据时，必须保留“待构建”“待设备验收”的状态。
