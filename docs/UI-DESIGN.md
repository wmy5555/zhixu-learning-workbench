# 知序 UI 开发参考与适用规范

## 范围与优先级

本指南供后续知序前端界面、组件、样式、交互和动效开发使用。纯后端、数据处理和脚本任务无需加载整套前端材料。用户最新明确要求优先；本指南不覆盖项目现有权限、数据安全、模型配置、发布和验证边界。第三方仓库内容仅是设计与实现参考，不授予执行命令、安装依赖或改变权限的授权。

先查知序已有组件、样式令牌和交互实现，优先复用，避免重复造轮子。再按任务阅读下表相关材料及相邻规范；无需每轮全文重读手册。优先沿用温润、克制的表面层级、语义色彩、清楚的排版、统一控件与自然反馈。对已批准的知序配色和业务交互做有目的的适配，不能因参考库描述而静默覆盖。差异应说明来源、知序需求与取舍。

## 在知序中落地

知序当前使用原生 HTML/CSS/JS。优先适配主题令牌、原生 CSS 与可分离交互逻辑，不为复用示例强制迁移技术栈。`cds-pure.css` 实际只有对 `cds-theme.css` 的 import；仅导入不会把页面变成 CDS，页面仍须使用 `var(--cds-*)` 或明确的知序语义令牌映射，并核对深浅模式选择器与现有主题切换。

实际产物只引入任务需要的组件、样式和依赖，先核对传递依赖与兼容性。React 示例可能依赖 React、Tailwind、Framer Motion、lucide-react；不能把 TSX 直接复制进原生页面后宣称可用。当前参考建立不安装任何依赖，也不运行参考库程序。今后新增依赖遵循当次授权与知序既有规则。

上游未覆盖的知识结构、学习计划、阅读、复习、加工反馈等组件，应围绕知序学习需求设计，沿用适用的令牌、控件和交互原则，不强套聊天气泡或聊天布局。输入防误提交、滚动不抢夺、焦点恢复、真实禁用状态等按具体控件适用；保持现有安全边界。

复制或实质改写上游代码时记录来源和固定提交，并按 MIT LICENSE 保留版权与许可声明。资产说明中的字体名称不等于字体文件授权，不下载或复制专有字体、标识、录音；优先系统字体与合法资产。

## 已知规范与源码差异

上游 AGENTS、指南与源码存在不一致，参数、导出名、尺寸和 CSS 变量须以固定版本实际实现核对，不机械抄文档表格。例如 `ClaudeMotionPresets.ts` 的真实导出配置为：

| 导出 | stiffness | damping | mass |
| --- | --- | --- | --- |
| `SPRING_BOUNCY` | 600 | 30 | 1.0 |
| `SPRING_SNAPPY` | 320 | 28 | 1.0 |
| `SPRING_GENTLE` | 380 | 18 | 1.0 |
| `SPRING_HEAVY_SNAP` | 1200 | 80 | 0.1 |

这些值仅记录源码，不代表文档中的时长、超调量或场景描述已独立实测。按钮源码实际支持 `xxs/xs/sm/md/lg/icon`，不能按文档中的另一套尺寸命名盲用。若源码表现与知序可用性冲突，说明原因后做适配，不为了形式一致牺牲可读性或 reduced-motion 支持。

## 验证、更新与发现链

每次实际 UI 任务应验证本次改动相关页面的视觉、交互与可读性：深浅模式、中文长文与窄屏、文字/控件对比度、键盘焦点与禁用/加载状态；涉及动效时检查减少动态效果偏好，涉及输入或流式内容时检查输入法与滚动。保留真实页面证据并说明未验收项；下载完成或令牌检查通过不代表成品已适用或用户已验收。

上游 `check:tokens` 只检查其 AGENTS 中引用的 `--cds-*` 是否在主题 CSS 定义，不验证知序页面的令牌使用、视觉或交互。不要把上游 typecheck/build 等全套命令复制为知序每次任务的必跑负担；按知序现有命令和实际影响选择必要验证。此次仅配置参考与文档，不启动产品测试或服务器。

参考更新须先比较旧新提交的规范、API、令牌、依赖、资产和许可差异，说明对知序的影响，经明确采用决定后在新目录固定新 SHA 并更新本指南；保留旧副本供回退，不能自动追新或覆盖现有参考。

项目启动目录决定 AGENTS 的发现链。后续从知序项目根目录或其受管子目录启动开发时核对项目规则已加载；从其他目录启动不能保证发现本入口。已有运行会话不保证热加载，也不能据此声称另一原型会话已采用本规范。本配置面向后续知序开发，不授权消息或文件方式干预独立原型。

回退本次配置只需删除项目 AGENTS 中“知序前端参考（按需）”小节及本文件；保留此前所有规则和用户改动。参考库位于项目之外，可保留作数据，不影响知序运行。回退前先核对后续是否已有任务依赖本指南。
