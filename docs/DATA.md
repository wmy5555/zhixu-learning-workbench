# 数据、调度与恢复

## 文件与记录

- `vault/01 原始资料`：真实收到的原文或已读取网页的摘录。网页摘录带原地址和定位，明确不等于完整网页。
- `vault/02 知识`：参考、候选、学习和确认后的个人知识。正式理解只能由用户确认；原始 AI 拆解与用户理解在正文中分别标注。
- `vault/03 错题修正`：问题、用户原答、AI 指出的问题、依据、后续练习与质疑状态。不进默认 RAG。
- `vault/04 主题` 和 `05 发现`：确认主题与自动发现报告分别标识。
- `.data/learning.sqlite`：回答、任务、调度、关系、草稿、提案、调用记录、历史版本、可重建索引，以及独立表中的加密凭据和恢复阶段证据。整个数据库仍属于私人资料。
- `.data/secrets.enc.json`：旧版加密凭据文件。首次迁入数据库后保留原文件，迁移标记防止下次启动重新导入已清除的旧密钥；不放在 Vault 或 JSON 备份里。加密继续使用 Windows 当前账号 DPAPI，其他系统需环境变量 `LEARNING_MASTER_KEY`。
- `.data/mcp-token`：仅本地 MCP 访问令牌。不要分享，备份不导出。
- `.data/chatgpt-mcp-token`：ChatGPT 专用桥接凭据，与上面的令牌隔离，不进入备份或回执。

ChatGPT 会话作为第一层原始资料保存，正文分开标注模型整理摘要、角色原文和实际收到的范围。设置中的 ChatGPT 读取许可属于独立的接收方授权：开启后读取的资料会进入 ChatGPT 上下文；该开关不授权其他模型、搜索或向量服务自动运行。关闭该许可立即停止后续读取，不会收回此前已经发送到 ChatGPT 的内容。

Vault 文件是知识内容权威。Web 修改前检查最新文件哈希；外部改名通过 frontmatter 的稳定 id 关联。没有 id 的旧文件暂用路径/内容匹配，首次经 Web 保存时写入 id；如在该步骤前同时重命名并改正文，身份无法可靠自动保持。未知 YAML 属性和 `.obsidian` 保留，程序不跟随目录链接。

发现重复 id 或无法解析的属性时，冲突文件从正常检索中隔离，系统页列出原因。不会选一边覆盖另一边。原始输入首次落盘即保留快照；用户主动修改仍可追溯历史。

## 设置与凭据

保存设置前会完整检查分组、开关、数值范围、时区、时间、服务地址及提示词变量。设置与加密凭据一起提交；任何字段无效或写入失败，旧设置和凭据继续保留，不会只保存一半。更换 Vault 的扫描也参加同一事务，失败时保留原目录与索引。

密钥绑定对应服务地址和模型。更换地址或模型后，旧密钥继续保留在本机，但不能用于新配置，须重新填写对应密钥；请求执行时也核对绑定，避免配置变化后把旧密钥发往新服务。空密钥保持原值，明确清除才删除；恢复 JSON 不导入、清除或重绑本机凭据。

## 备份与恢复

系统页可下载开放 JSON，包含知识文件、运行与学习记录、历史和非敏感偏好；密钥和 MCP 令牌不导出。恢复先预览数量，再用绑定内容的短期确认凭据执行；恢复前自动生成 `.data/backups/before-restore-*.json`。详见恢复测试记录。

导出和恢复都以最终 JSON 的 UTF-8 大小为准，上限为 **100,000,000 字节**，包括 JSON 转义、历史、运行记录与偏好设置。单份 Markdown、历史正文及普通运行记录 JSON 最多 5,000,000 字节。调用响应记录 `callResults` 单独处理：解码后的响应正文最多 3 MiB，正文以外的字段 JSON 最多 5,000,000 字节；序列化记录最多 23,874,368 字节，容纳引号、反斜杠及控制字符的 JSON 转义。该记录仍计入整包 100,000,000 字节上限。恢复 HTTP 请求单独允许 100,065,536 字节，留出确认字段的空间；其他接口不扩大容量。超限会明确拒绝，不删减内容。

恢复预览先检查 Markdown 属性、数据结构、身份与路径重复、运行记录、历史哈希及偏好设置；主题和关系镜像也须可一致重建。非法输入不会改变当前资料或数据库。正式库恢复将资料和设置一并提交，模型、向量、搜索、网页读取和全部 MCP 权限均关闭；排队或运行中的备份任务变成等待，须在任务页确认后手动重试。练习备份只恢复隔离的学习偏好，外部能力仍继承正式库设置。

恢复阶段记录保存在 Vault 的 `.learning-restore-*` 暂存目录，并与 SQLite 中的计划摘要和提交标记核对。进程被强制结束后，下次启动在正常扫描前处理：尚未提交且原件证据完整时恢复原状；已提交且新文件与数据库一致时完成清理。恢复处理再次中断仍保留原件。文件被外部修改、出现未知文件或证据不一致时保留现场并停止，普通失败回滚也不会删除新出现的外部修改。此时请保留暂存目录和安全备份供维护核对，不要直接删除暂存目录绕过提示。该机制已覆盖进程强杀测试，不代表所有断电或硬件损坏情形都已验收。

恢复旧备份会保留本机已有调用的账本、响应和费用记录。同一操作即使在另一台机器生成了不同调用编号，也以本机证据为准，冲突的异机调用整组不导入；批改还按原轮次识别，变更模型或提示词不能绕过。其他操作和普通多步骤任务中的不同请求历史可补入；缺少必要记账或响应证据的备份会被拒绝。复用响应时只要同一操作仍有未决调用或存在多条候选记录，就停止并要求核对，不猜选最新响应。

**附件与 Obsidian 配置**：当前文本版备份针对受管理的 Markdown 与应用记录。外部放入 Vault 的图片、PDF、音频及 `.obsidian` 配置请随整个 Vault 另行复制；JSON 恢复不覆盖这些文件。完整机器迁移建议在停止服务后复制 Vault 和 `.data`，并重新配置 API 密钥（DPAPI 密文与 Windows 账号绑定）。

删除只移除当前知识文件、检索片段和研究缓存；历史版本与以前下载的备份仍可能有副本。历史恢复是明确操作，重建索引不会自动恢复删除内容。恢复或合并可能影响多个笔记，请检查预览。清除历史和备份文件是单独的人工维护步骤。

## 外发流程升级与回退

升级不会批量改写 Markdown，也不删除旧 `privacy` 或未知属性；旧客户端提交的资料分类字段被忽略。新资料没有云端许可，旧版回退时仍按原有保守规则处理。合并和链接同步保留必要的旧版保守元数据。旧的本地或无授权学习历史不会因升级自动进入新的跨会话批改上下文。

新任务记录操作版本；升级前待执行的外部任务进入等待，主动点击 AI 拆解可继续对应任务，并以本次是否联网核验为准；任务页明确重试原联网任务时保留其选项。恢复备份后所有排队任务都等待主动重试，即使备份含新操作标记。保存、阅读、启动和调度本身不成为外发授权。代码回退不会撤回已发送请求；请保留回退前的正常备份。

## 调度与费用

本地服务每 3 秒检查任务。到用户设置的生成时间后，为当天安排预算内的学习；生成键由日期和知识 id 组成，重复触发不会重复建任务。主机恢复后补算今天，不累积此前每一天的学习欠账。

运行中的外部任务遇到服务重启，会进入等待并保留原因。每次外发先保存额度预留和调用状态，再发送请求；已发送但结果未知、或收到响应但记账失败时，暂停新调用，即使月预算设为 0 也不绕过。已保存的响应可先补记账，再手动恢复原任务，复用该响应；同一轮批改更换模型或提示词也不会重新发送。没有响应的调用须先核对账单：费用仍未知就继续暂停，确认已知金额只允许符合其他限制的新操作，不会重发原调用。具体操作见 [用量与费用](USAGE.md#中断调用怎样处理)。

已读证据缓存可复用；研究未完成的缓存不会阻止显式继续。单纯缺少单价或用量、但调用已完整记账时仍显示费用未知，启用正金额月预算后会阻止新请求。月预算依据已记录及预留的费用在发送前检查，单次实际费用仍可能超过估算的剩余额度；供应商最终账单是费用依据，每日调用次数另有硬上限。

## 隐私与安全

资料不再分“仅本地/允许外发”。普通保存、阅读和后台发现不调用外部服务；主动 AI 拆解默认使用完成拆解所需的原文，不逐份重复确认。联网核验仍需主动选择，查询、问答、AI 关联及语义索引保留各自的主动入口；一次拆解不授权这些入口后台运行。联网核验只发送候选事实和必要正文，关系探索只发送有限候选。

服务仅绑定 `127.0.0.1`，检查访问域与来源；Web API 要求本机同源会话及防跨站操作标记。MCP 使用独立本地令牌，默认关闭，默认只读；提案先在 Web 显示原文和建议，确认且版本一致后才写入。

网页、笔记和模型输出均是数据。渲染使用安全 DOM 文本节点；模型只能返回数据，不能执行文件命令。网页读取逐跳检查地址与 DNS、固定连接目标，拒绝私网和回环地址。当前版本不支持访问本机模型端口；供应商端点需 HTTPS 公网地址。

## 2026-09-29：文件权威与增量同步

已确认关系以知识 frontmatter 的 relations 为准，主题成员、顺序、暂停以主题的 noteIds/paused 为准。扫描可从同一 Vault 为新的数据库重建这两种镜像；外部移除确认关系会保留历史状态，缺失端点、重复定义和不一致定义进入冲突提示，不把它们继续当作已确认关系。学习回答、使用记录、建议处理记录等仍属于运行数据，需正常备份 SQLite 或导出的应用 JSON。

Obsidian 的自动链接只写在有校验记录的管理区。更新前检查预览哈希；改名可重新找到目标稳定 id，用户改过管理区则拒绝覆盖。每次主动外发仍复核当前文件、链接管理区与引用完整性；缺失目标、冲突和过期快照会阻止请求。旧隐私字段仅为回退兼容保留，链接同步与合并保留旧版可识别的保守值，不再作为当前版本的资料分类。

索引重建复用正文相同且模型相同的片段；元数据变动不清空现有向量。诊断显示缺失片段数量，补建入队时固定资料身份和内容哈希，执行仅发送仍匹配的版本，排队后新增或修改的资料不进入该次外发。主动重试索引任务会重新固定当前清单；缺少入队快照的旧索引任务等待主动重试。执行中继续核对资料和引用，不自动对新增内容收费。

每日安排优先到期复习与开放误解，并考虑主题前置顺序。结束练习结算一次，跨日按设置中的时区统计，同日追加练习不连续翻倍。自动发现仅进行有界、轮换的本地比较；AI 查询扩展、语义召回与细查需主动勾选。
