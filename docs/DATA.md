# 数据、调度与恢复

## 文件与记录

- `vault/01 原始资料`：真实收到的原文或已读取网页的摘录。网页摘录带原地址和定位，明确不等于完整网页。
- `vault/02 知识`：参考、候选、学习和确认后的个人知识。正式理解只能由用户确认；原始 AI 拆解与用户理解在正文中分别标注。
- `vault/03 错题修正`：问题、用户原答、AI 指出的问题、依据、后续练习与质疑状态。不进默认 RAG。
- `vault/04 主题` 和 `05 发现`：确认主题与自动发现报告分别标识。
- `.data/learning.sqlite`：回答、任务、调度、关系、草稿、提案、调用记录、历史版本和可重建索引。
- `.data/secrets.enc.json`：Windows 当前账号 DPAPI 密文；不放在 Vault 或备份里。其他系统需环境变量 `LEARNING_MASTER_KEY`。
- `.data/mcp-token`：仅本地 MCP 访问令牌。不要分享，备份不导出。

Vault 文件是知识内容权威。Web 修改前检查最新文件哈希；外部改名通过 frontmatter 的稳定 id 关联。没有 id 的旧文件暂用路径/内容匹配，首次经 Web 保存时写入 id；如在该步骤前同时重命名并改正文，身份无法可靠自动保持。未知 YAML 属性和 `.obsidian` 保留，程序不跟随目录链接。

发现重复 id 或无法解析的属性时，冲突文件从正常检索中隔离，系统页列出原因。不会选一边覆盖另一边。原始输入首次落盘即保留快照；用户主动修改仍可追溯历史。

## 备份与恢复

系统页可下载开放 JSON，包含知识文件、运行与学习记录、历史和非敏感偏好；密钥和 MCP 令牌不导出。恢复先预览数量，再用绑定内容的短期确认凭据执行；恢复前自动生成 `.data/backups/before-restore-*.json`。详见恢复测试记录。

**附件与 Obsidian 配置**：当前文本版备份针对受管理的 Markdown 与应用记录。外部放入 Vault 的图片、PDF、音频及 `.obsidian` 配置请随整个 Vault 另行复制；JSON 恢复不覆盖这些文件。完整机器迁移建议在停止服务后复制 Vault 和 `.data`，并重新配置 API 密钥（DPAPI 密文与 Windows 账号绑定）。

删除只移除当前知识文件、检索片段和研究缓存；历史版本与以前下载的备份仍可能有副本。历史恢复是明确操作，重建索引不会自动恢复删除内容。恢复或合并可能影响多个笔记，请检查预览。清除历史和备份文件是单独的人工维护步骤。

## 调度与费用

本地服务每 3 秒检查任务。到用户设置的生成时间后，为当天安排预算内的学习；生成键由日期和知识 id 组成，重复触发不会重复建任务。主机恢复后补算今天，不累积此前每一天的学习欠账。

运行中的外部任务遇到服务重启，会进入等待并保留原因，需要重试，避免自动重复计费。网络请求有超时、有限重试和并发限制。已读证据缓存可复用；研究未完成的缓存不会阻止后续重试。搜索与模型费用未知时按未知记录，月费用未知且启用正金额预算时拒绝继续。月预算依据已记录的费用在请求开始前检查，单次在途请求仍可能超过剩余额度，供应商最终账单是费用依据；每日调用次数另有硬上限。

## 隐私与安全

默认仅本地。允许某份资料外发与允许某次问题外发是两个选择。仅本地资料不进入外部模型或向量服务；联网核验只发送候选事实和必要正文，关系探索只发送有限候选，不整库逐篇外发。

服务仅绑定 `127.0.0.1`，检查访问域与来源；Web API 要求本机同源会话及防跨站操作标记。MCP 使用独立本地令牌，默认关闭，默认只读；提案先在 Web 显示原文和建议，确认且版本一致后才写入。

网页、笔记和模型输出均是数据。渲染使用安全 DOM 文本节点；模型只能返回数据，不能执行文件命令。网页读取逐跳检查地址与 DNS、固定连接目标，拒绝私网和回环地址。当前版本不支持访问本机模型端口；供应商端点需 HTTPS 公网地址。
