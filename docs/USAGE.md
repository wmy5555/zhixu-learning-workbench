# 用量与费用

## 单任务请求额度

默认 120 次，可在「系统 → 用量与费用」设置为 1–300 的整数。一个任务中的模型、搜索、网页读取、重定向和重试共用总额度，分批不会重置计数；任务完成后立即停止。现有明确保存的额度保持不变，可自行调整。

每组最多 3 项主张、2 个检索方向、4 个网页及 1 次评价；24 项主张基础请求约 57 次（含一次拆解），重复网页可能减少请求，重定向和重试可能增加请求。额度不足保存进度，用户选择继续时优先处理未检索的主张。每日总上限、月预算、各功能的主动操作要求仍独立生效；更高请求额度不保证网站可读取或证据充分。

更新后端代码后，需要正常重启程序才能加载修复：先等正在运行的任务结束，运行项目的 `stop.cmd`，再运行 `start.cmd` 并刷新页面。可按需要调整单任务额度，每日上限和月预算继续独立约束。保存额度不会自动重试任务或发起外部请求。

在「系统 → 用量与费用」查看知序产生的外部调用。页面提供今天、近 7 天、近 30 天和本月四种范围，可筛选服务或模型，切换 token、费用和请求趋势，展开每日和最近请求明细，并导出当前统计的 JSON。

## 怎样读这些数字

「最近外部调用」与最近请求明细优先显示业务用途，同时保留模型和底层服务类型。用途来自实际操作入口，例如资料拆解、单资料逻辑图、跨资料关联、问答、提纲/草稿、教学反馈、标题生成、连接测试、检索索引及学习包建议；一次操作中的搜索或网页读取沿用该业务用途，可组合用途、服务和模型筛选。

旧记录仅在账本中有明确任务或问答请求关联且关联记录仍存在时读取用途；只有模型名、提示词、上下文哈希或资料 ID 时不猜测，显示「历史用途未记录」。此展示补充不回写历史记录，不改变费用、预算和恢复语义。

- **Token** 是模型处理文字时使用的计量单位，不能直接当成中文字数。总数为输入加输出；缓存命中输入已包含在输入中，推理 token 已包含在输出中，不能再加一次。
- **外部请求** 包括模型生成、语义嵌入、搜索、网页读取和连接测试。额度核对也包含进行中的持久预留，预留不代表已经发送；确定未发送的预留取消后不计请求。一次资料加工可能使用多次请求；本机缓存或已保存响应直接命中时没有新增外部请求。
- **传输状态** 只表示连接和 HTTP 响应情况。HTTP 响应成功后，仍可能因无效 JSON、空内容、截断或格式校验失败而导致操作失败；实际结果以对应操作页面或任务结果为准。统计中的失败次数只计算连接或 HTTP 失败；导出数据以 `resultScope: "transport"` 标明 `ok`、`failedCalls` 的范围。
- **已记录费用** 是按请求发生时保存的用量和你填写的单价计算的估算值，实际费用以供应商账单为准。缺少单价、用量或请求结果不明时，保留“未知”；失败不等于免费。
- 小于显示精度的正费用使用 `< 0.000001`（概览为 `< 0.0001`）提示，不显示成免费；导出保留原始金额。
- 旧记录没有缓存或推理细分时，不根据文字长度补猜。费用明细会显示“已知金额 + 未知”；概览卡片也会提示仍有多少次费用未能确认。
- 趋势和总计使用所选期间的全部调用记录；最近请求表最多显示 100 条，每页 10 条。汇总不受这 100 条的限制。

日期使用正式库「能力设置」里的时区。顶部今日请求和本月费用始终表示所有服务的共同额度，不受下方模型、日期筛选影响。教程模拟日期也不影响真实用量统计。

## 设置预算和单价

每日请求总上限和月预算已从文本生成设置移到此页。默认每日 500 次；每日上限设为 0 会暂停外部请求。月预算为 0 表示未启用月费用上限；设置为正数后，本月费用未知或已达到预算都会阻止新请求。请求前持久保存预留，并核对其他在途调用；单次实际费用仍可能超过估算的剩余额度。结果未知或记账未完成的调用另有恢复保护，月预算为 0 也不能绕过。

单价与预算须使用同一货币单位，例如全部使用人民币。系统不会自动判断币种或换汇；不同币种的供应商价格需先换算为同一单位。

| 设置 | 填写方式 |
| --- | --- |
| 输入、输出单价 | 当前文本模型每百万 token 的价格 |
| 缓存命中输入单价 | 可选。留空时全部输入按普通输入价估算；填写后必须有供应商报告的缓存数量，否则该次费用未知 |
| 语义嵌入输入单价 | 当前向量模型每百万输入 token 的价格 |
| 联网搜索单价 | 当前高级搜索每次成功 HTTP 请求的价格；连接或 HTTP 失败时费用仍未知，响应内容无效不代表免费 |

留空表示未知，只有明确免费才填 0。价格只影响后续请求；历史记录不会因新价格被改写。更换模型或服务地址会清除该服务旧单价，避免沿用错误价格；若页面打开后模型已在别处变化，保存时会要求刷新。保存单价不会启用能力、替换凭据或发起供应商请求。

练习空间和正式使用共用同一份实际调用记录与额度。练习中只能查看，修改需退出练习到正式库。本页不查询 Codex/ChatGPT 账户的订阅额度，也不读取它们的会话日志。

## 中断调用怎样处理

在正式库的「系统 → 用量与费用」核对待处理调用。系统先保存预留，再记录已发送、已收响应与记账完成，避免重启后把尚未完成的调用当成没发生。结果未知或记账失败会暂停新外发，不自动重试供应商请求。

- **已保存完整响应**：先恢复记账，再到任务页手动重试原任务，系统复用保存的响应，不新增这次供应商请求。同一轮学习批改绑定原轮次，修改模型、服务或提示词也不会再发一次。响应内容仍须通过原有解析、版本和权限检查，收到 HTTP 响应不等于批改成功。
- **没有完整响应，费用未知**：核对供应商账单并记录原因；确认时仍选择未知，系统继续暂停。网络中断不能当作免费。
- **没有完整响应，费用已确认**：填写核对金额与原因后，可在其他预算和权限条件满足时发起新操作。原调用仍没有可恢复结果，原任务不会因此重新发送。
- **确定尚未发送的预留**：恢复处理可取消预留并释放这次额度，不把它记成已发生的供应商调用。

恢复旧备份保留本机已有调用的整组账本、响应与费用，同一调用身份优先使用本机证据；不同调用的历史可补入。恢复不能降低已发生的本机费用，也不能借导入响应绕过未知调用保护。缺少单价但已完整记账的“费用未知”，仍按月预算规则处理，与“请求结果未知、需先恢复”的情况分别显示。

## 开源参考与实现边界

参考 [ccusage](https://github.com/ccusage/ccusage/tree/250b4b8c24d2154e80e223708cf16ea34f5dc47c) 的按日、按模型分组和缓存输入统计方式。检查了该版本的 README、[Codex 报表实现](https://github.com/ccusage/ccusage/blob/250b4b8c24d2154e80e223708cf16ea34f5dc47c/rust/adapters/codex/src/report.rs) 及 [MIT 许可证](https://github.com/ccusage/ccusage/blob/250b4b8c24d2154e80e223708cf16ea34f5dc47c/LICENSE)。知序使用自己的调用记录和原生 JavaScript 实现，没有引入上游程序、代码文件、价格库或依赖，也不自动联网获取价格。缺失费用在知序中继续保持未知。

页面采用用量概览、时间筛选、趋势和管理入口的层次组织，参考 Codex/ChatGPT 使用统计的呈现方式及 [OpenAI 使用量界面指引](https://developers.openai.com/siwc/ui-ux-guidelines)。不复制其账户额度，也不暗示与供应商账单同步。

## 开发与验收

`GET /api/usage?period=month&capability=model&model=...` 返回完整期间汇总、每日分组、模型分组、最近 100 条经过字段筛选的记账明细及共同预算状态。需现有 Web 会话；不提供新 MCP 权限。`PUT /api/usage/settings` 复用 CSRF 校验并只接受预算、单价及用于防止过期保存的模型标识。练习路由返回正式共用统计，写入受练习限制。

`src/token-usage.mjs` 读取供应商报告的非负整数，包括兼容接口的缓存细分和 DeepSeek `prompt_cache_hit_tokens`；无使用量时不自行估计。每次真实 HTTP 尝试仍只记录一次，记录与 `generate().usage` 使用相同计价逻辑。

`src/call-ledger.mjs` 在 SQLite 中持久保存预留、发送、响应与记账状态。恢复接口只处理本地证据或人工费用确认，不发送供应商请求：`GET /api/call-recovery` 查看待处理调用，`POST /api/call-recovery/:id` 提交 `action: "recover"`，或 `action: "confirm"` 加 `cost`（未知为 `null`）和 `reason`。沿用会话、CSRF 和正式库写入限制。调用状态不保存请求正文或密钥；受限响应正文只供本地恢复，属于私人资料。

本地回归覆盖：缓存/推理去重，缺失与异常计数，零价格，嵌入仅返回总 token，成功搜索计价与缓存不重复记账，超过 100 条汇总，跨月/时区/夏令时，历史费用不回写，模型变化时清除单价，过期保存拒绝，练习只读，会话/CSRF 检查，异步筛选竞态和能力设置不覆盖预算。

本次调用中断恢复的 15 项定向测试已通过，使用随机临时目录、合成资料和受控响应。最终综合验证、浏览器界面验收、真实供应商账单核对及付费调用仍待完成；不把受控响应描述为真实供应商成功。

## 原始资料回收站

原始资料的“移入回收站”会从当前列表移除资料，原文、附件和资料身份保留。点击左下角垃圾桶图标进入回收站，逐项恢复。已有知识与学习记录保持关联；其他内容的版本历史不属于回收站。

“一键清空回收站”需要再次确认，只清理当前资料库中的回收站原始资料、其历史版本和未被其他内容引用的受管理附件，无法从回收站恢复。已有知识、学习记录、共享附件及独立备份保留。确认期间列表变化时会要求重新确认；文件占用导致清理中断时会保留待清理记录，再次明确确认后重试。文件或路径发生冲突时保留并报错。

## 诊断状态的阅读方式

“系统 → 诊断与 MCP”中的存储和索引以当前资料库为准；练习库会明确标注，不能据此判断正式库设置。索引数量按内容片段统计，一篇资料可能包含多个片段。没有冲突、没有待更新链接和没有调用记录分别显示空态，数据缺失则显示未知。

外部应用接入分别展示本机工具许可、修改建议许可、ChatGPT 会话收集和读取知识库许可。开关开启表示允许使用对应能力，不能证明客户端已经配置或 ChatGPT 网页已经连通；实际连接仍需按连接指南验证。允许 ChatGPT 读取时，包含仅本地资料，读取内容会进入 ChatGPT 上下文。

排查问题时，可展开“技术详情”查看原始路径、协议和记录。补建语义索引可能外发片段并产生费用；删除不会清除已有历史版本或此前导出的备份，备份范围以面板保留提示和备份恢复说明为准。
