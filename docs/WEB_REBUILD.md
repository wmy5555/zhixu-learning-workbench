# 网页前端重构 · 2026-10-20

网页入口从指定原型重新构建。`public/index.html` 只加载 `public/web/` 中的新模块，不导入旧版 app、UI、主题、样式或引导代码。此轮只交付网页端，没有修改 Android/iOS 工程。

## 设计依据

- 主视觉：用户选定的 `http://127.0.0.1:14328/` 融合原型，其实际文件为本机 `zhixu-home-fusion/home.css` 与图标定义。保留暖灰、陶土色、宋体标题、自然留白及今日学习布局。
- 书桌：`http://127.0.0.1:4329/?prototype=home&variant=C`，用于独立阅读页面的排版参考。采用资料导航、受控行宽正文和学习操作侧栏；窄屏将操作放入独立菜单。
- CDS：固定 `4045ce76afdcb7dccef1b7e6417b04c4c6046e9c`，经指定原型中的主题、`ClaudeMotionPresets.mjs` 和原生动画桥接接入。版权和 MIT 许可保存在 `public/web/cds/LICENSE.txt`。没有新增字体、图片或依赖。

## 已接入的核心流程

- 今日清单、延期、重新安排、学习时间预算、最近内容及实际后台状态。
- 完整原文保存、可选 AI 拆解及从属联网选项、文本读入、图片/PDF/Word 原件上传与保存。
- 知识库分类和本地筛选；独立书桌、章节目录、字号、专注阅读、原件下载与图片展示。
- 带版本冲突保护的编辑、手工整理知识、学习用途选择、本人确认理解、依据读回。
- 学习池与会话恢复、先读后回忆、回答保存、防重请求、提示、真实反馈状态、结束练习以及错题判断。
- 创建主题学习包、本地/混合检索、问答/提纲/草稿、引用回读与草稿编辑。
- 学习节奏、独立明暗偏好、模型连接设置、显式连接测试、备份下载与回收站恢复。

设置只提交用户编辑的字段；密钥不读回、不写浏览器存储。模型和联网仍需明确动作，费用和等待状态不伪装为完成。后端会话/CSRF、权限、核验、晋级和数据契约不变。

复杂关系可视化、完整新手教程、全部高级配置与管理报表暂未重建。此轮不恢复每个旧页面和按钮；已有数据与后端能力保留。

## 验证边界

`tests/web-client.test.mjs` 覆盖新入口依赖边界、AI/联网依赖、未完成任务计时、安全 Markdown、会话原文、未知网络结果不自动重发，以及真实临时 HTTP 服务中的收集→检索→手工整理→学习→保存回答→过期编辑拒绝。

浏览器只用隔离工作区的合成资料，实际操作了保存、搜索、目录定位/字号、学习作答、主题保存、本地输出和学习偏好；检查日夜与 390px 窄屏、减少动态效果。证据位于本机忽略目录 `.tmp/evidence/`，不包含真实用户资料，不上传到公共仓库。

没有调用真实 AI 供应商，没有执行全套产品回归或 Android 验收。实际运行不等于用户最终审美验收。正式部署另外核对进程、固定提交、所有新网页资源和桌面启动入口；部署前保留上版提交与配置。
