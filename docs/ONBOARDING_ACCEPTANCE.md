## 自动验证的行为

| 检查 | 验证内容 |
| --- | --- |
| 全流程接口 | 在同一练习空间依次执行 12 章主要操作，再重新检查前面步骤的完成记录；正式资料、学习记录、关系、主题、任务和设置保持原值。 |
| 空间隔离 | 正式与练习请求明确分流；错误或已重置的身份直接报错。练习删除、合并、恢复、重置不会写入正式库。正式 Vault 与练习目录不能互为父子目录，文件链接也不能绕过检查。 |
| AI 前置条件 | 未测试连接不能开始主线写操作；保存连接配置后旧验证失效，测试期间修改配置也不能取得成功凭据。密钥不进入教程进度或练习备份。 |
| 共享调用 | 练习与正式操作使用同一个 AI 调用器，日预算和并发预留共用；练习研究使用自己的提示词，模板变化清理对应研究缓存。 |
| 学习时间 | 同日追加不增加间隔，到期跨日独立完成才增加；提示或错误保留近期安排；延期和资料过期依据演示时间，文件历史、备份、超时和请求额度依据真实时间。 |
| 防止虚假成绩 | 仅推进日期不会新增成绩；已提交但未结束的回答不能通过加速日期变成新的一天独立回忆。预设会话不能完成真实学习步骤。显式结束未完成练习会保留回答并解除时间限制，不新增成绩，旧任务也不会再次付费批改。 |
| 完成证据 | 下一步和阅读确认不能代替实操；追问需要第二轮反馈；取消采用必须实际撤回过采用标记；关键词回退不能算语义成功，本地引用列表不能算 AI 输出成功。 |
| 暂停与恢复 | 等待进行中的请求结束；重启、暂停和恢复后，未完成任务等待用户主动重试。恢复携带示例身份映射，进度独立核对；向量需主动重新补建。 |
| 备份与配置 | 练习备份有用途标识，正式恢复入口拒绝它；练习恢复不能改正式路径、连接配置或凭据。附件与 `.obsidian` 不在 JSON 备份内。 |
| 界面状态 | 标签页各自保存空间身份；切换前等待请求，清理旧页面状态；案例目标、抽屉重新定位以及不可跳过的实操判定有自动回归。 |
