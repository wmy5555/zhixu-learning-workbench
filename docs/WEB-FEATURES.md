# 网页功能与学习计时

新版沿用现有字号、陶土配色、侧边栏和阅读布局。扩展功能放在详情与设置中；首次打开仍使用默认外观。

## 功能入口

| 入口 | 可用操作 |
| --- | --- |
| 检索与发现 → 知识联系 | 查看关系的类型、用途、边界，发现联系，接受、拒绝、移除；处理整理建议 |
| 主题学习包 → 详情 | 查看进度与前置知识，按序续学，编辑成员和顺序，复制、拆分副本，暂停与恢复 |
| 阅读 → 更多操作 | 完整出处及日期、定位、核验期限，历史版本正文和恢复，知识合并预览，Obsidian 链接预览，可恢复移除 |
| 知识库 → 更多筛选 | 学习状态、资料类别、主题包和报告，原文分组与子知识导航 |
| 收集与加工 → 文本文件 | TXT、Markdown 批量预览与导入；原有图片、PDF、Word 入口保留 |
| 检索 → 检索方式与筛选范围 | 关键词、纯语义、混合；类别、阶段、来源、主题、日期及诊断。语义方式需明确允许外部嵌入 |
| 问答与输出 | 选择取材范围；查看引用摘录、角色、理由、定位与核验时间；草稿标记实际采用的知识、送回收集箱 |
| 学习与复习 → 完整历史 | 分页查看全部学习记录；每轮提示、原文重看及独立回答分别记录 |
| 系统设置 → 更多设置 | 独立能力配置与测试、接入授权、时区与存储、强调色、提示词、用量费用、索引提案、备份恢复 |
| 任务记录 | 筛选、分页、取消与重试；重试前确认可能的外部调用 |
| 今日安排 → 更多 | 今日跳过、暂停知识；折叠区域提供恢复入口 |

已有历史 `privacy` 字段仅显示。后端不把它作为可编辑的逐条授权开关；此版本没有改变外发权限机制。外部连接测试只在明确点击并确认后进行，测试请求可能产生费用。

知识移除保留历史版本，可在设置中的“恢复已移除知识”找回。原始资料沿用回收站恢复。完整备份先显示差异，再用对应预览确认恢复；恢复后外部能力关闭。本次扩展不提供新的永久删除能力。

调用汇总覆盖所选范围；明细与 CSV 导出覆盖服务返回的最近 100 条，界面明确标注范围，未知费用不会显示为免费。

## 网页番茄钟

“开始番茄钟”位于首页可用时间卡片的“调整可用时间”右侧。默认专注 25 分钟，可设为 1–120 分钟；休息默认 5 分钟，由用户主动开始。

计时启动后替换“已安排分钟”区域。切换页面后收缩成侧边栏旁的番茄圆环方块；拖拽或方向键可以移动，点击展开。到期在当前位置展开，并显示一次网页提示。减少动态效果偏好会禁用移动动效。不请求系统通知权限，不播放声音。

采用开始时间和累计运行时间计算，后台标签恢复与刷新后会补算至计划到期时刻。暂停不计时；主动结束只记已运行时长；同轮到期或重复结束不会重复写入。多个标签共用浏览器存储锁。

学习时长页可从计时器、学习历史区域或设置进入，按结束日汇总专注计时，分页保留每轮记录。休息、页面打开时间和暂停时间不计入学习；主动计时也不证明实际专注程度。

记录属于当前浏览器来源及当前知识空间，保存在浏览器本地存储。需要支持 Web Locks 的现代浏览器；存储失败会明确提示，不能假装已经启动。记录不跨设备同步，也不包含在知识库完整备份中，请使用“导出计时记录”另存 JSON。清除浏览器站点数据会影响这些记录。

## 隔离验证

`node scripts/parity-preview.mjs <固定基线目录>` 创建独立合成资料库与两个回环随机端口，并将预览信息写入 `.tmp/parity-preview.json`。调度与外部能力关闭。此脚本用于开发验证，不会接管常用服务或真实资料目录。

浏览器验证脚本接受已安装 Playwright 模块目录和 Chrome 可执行文件路径作为前两个参数，不负责安装依赖。`parity-workflows.mjs` 验证真实本地 API；`parity-boundaries.mjs` 的外部能力测试使用明确标注的模拟响应，不代表真实供应商验收。
