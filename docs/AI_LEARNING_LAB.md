# AI 学习优化：隔离验收

2026-10-22。仅 14338，正式 4318 不在本轮部署范围。目标是帮助用户独立解释、发现缺口、迁移使用，并保留资料与学习证据的区别。所有练习使用公开或合成材料，真实调用沿用已获用户授权的服务配置。

## 已落地与实测

| 方向 | 优化前 | 本轮结果 |
| --- | --- | --- |
| 完整学习单元 | 206 字材料拆 7 条；209 字材料拆 6 条 | 同材料分别 2 条、3 条，原文保留 |
| 出题与评分 | 通用题可能要求材料未给的机制 | 拆解时一并给材料题与逐字依据，打开练习不增加请求 |
| 回答判定 | 迁移题把个人场景判为缺少团队场景 | 同一答案复测 correct；完整/关键遗漏/相反答案分别 correct/partial/incorrect |
| 反馈 | 同时展开全部解析 | 关键反馈先显示，其余默认折叠；桌面与 390px 真页面核对 |
| 输出 | 同题草稿 625 字符，模板栏目偏多 | 同题草稿 268 字符；问答 362→266；引用与个人方法边界保留 |
| 检索 | 已整合的阅读知识排在团队行动前 | 同一查询前三位均为团队复盘相关资料 |
| 学习包 | 缺口和泛化说明较多 | 两个任务包均含可执行练习、自检；没有虚构前置知识 |
| 新手 AI | 第一轮接通真实模型 | 真实回答建议闭卷解释与换场景检验，不把点击完成说成掌握 |

正文长度去除引用标记后按字符统计，不是 token 数。提纲由 1441 字符变为新任务的 299 字符，但任务不同，不能作为同题效果对比。上述少量合成案例不代表通用模型准确率或真人学习增益。

## 功能覆盖与边界

- 新手 AI、多轮追问、不虚称掌握：真实模型返回。核心教程 28/28 包含阅读确认、真实操作证据；部分通过 API 完成，浏览器实际隐藏材料、提交答案及查看反馈。不是 28 项全浏览器走查。
- 标题与拆解、原文结构：第一轮真实生成/结构处理；本轮同材料拆解复测。标题随拆解同次生成。
- 学习、提示后追问、错题、理解确认、应用：第一轮覆盖提示/错题，本轮复测完整、遗漏、错误与迁移；用户理解确认使用明确标记的合成内容。
- 到期复习：练习时钟推进到第二天，真实模型判定 correct，复习间隔 1→2；没有改变电脑时间，也不能当作真实隔天记忆测量。
- 索引/语义检索：真实嵌入与检索成功；最终查询 0.87 秒，仅单次观察，存在后生成片段尚待索引的提示，不算性能基准。
- 问答、提纲、草稿、编辑及采用：真实返回、保存与使用记录核对。一次已记账回答因实验启动器漏传凭证被阻止，修正启动器后原响应本地取回，无新增调用。
- 关联：第一轮真实关系生成完成；本轮已添加来源分组和具体练习要求，发现任务中的关联细查超时，因此不称本轮完整通过。
- 发现：真实摘要包含可操作的跨主题问题，但还把同源互补条件称作“张力”、篇幅仍偏长；后续关联细查因嵌入连接超时未完成。
- 联网核验：公开 Python 材料 4 个主张中 3 个取得证据，另一个搜索超时；知识保留未完成提示，不把来源搜索结果当成核验成功。

## 费用与恢复

第一轮共 46 次外部调用、80,528 个已报告 token；两轮累计 85 次、152,168 个已报告 token，本轮增量 39 次、71,640 token。统计包含模型、搜索、嵌入与网页读取，token 仅含服务实际报告的记录。

累计 4 笔结果未知（3 次嵌入、1 次搜索）；这些金额仍为未知，未填成免费。其余服务也没有完整货币费用回执，无法可靠给出总金额。未知费用确认仅允许不同的新请求；已超时的原任务未重发。每日调用上限仍为 1000，配置本来未设月金额上限；如果启用设有金额上限的月预算，未知费用仍阻止调用。

实验开关 allowUncertainContinuation 默认关闭，仅实验启动器启用，不可因本报告将其推广至正式。旧请求的输入、响应、账本、待处理状态均保留。
