# 知序 · 个人学习工作台

[![CI](https://github.com/wmy5555/zhixu-learning-workbench/actions/workflows/ci.yml/badge.svg)](https://github.com/wmy5555/zhixu-learning-workbench/actions/workflows/ci.yml)

当前版本 **0.1.0 开发预览**。仓库已由所有者确认公开，尚未选择项目开源许可证或添加 LICENSE。

历史审计与当前状态见 [Public Release Audit](docs/PUBLIC_RELEASE_AUDIT.md)，依赖及资产来源见 [第三方许可证清单](docs/DEPENDENCY_LICENSES.md)。后续变更继续增量检查；项目许可证和新的可见性变更仍由所有者明确决定。

本地运行的中文 Web 应用。原始资料、知识、个人理解和错题修正保存为 Markdown；学习记录与任务保存到 SQLite。支持 Obsidian 外部编辑、来源追踪、独立配置的模型/搜索/向量服务和真实 MCP。

**当前状态：可运行开发版。** 本地数据流程、权限与 MCP 已实测；2026-09-20 已记录过真实模型的合成资料调用成功；这不代表当前用户配置或所有供应商的完整验收。真实资料的联网核验质量、语义检索质量和教学反馈仍需独立验收。没有把模拟结果当作在线成功。详见 [测试结果](docs/TEST_RESULTS.md) 和 [需求覆盖](docs/COVERAGE.md)。

## 在这台 Windows 电脑使用

开发候选支持保存后的原文读回核验，以及本机确认的「撤销本次保存 / 恢复撤销」。历史长会话可独立分批保存，但仍受 2 MiB 本机传输上限限制；整批撤销尚未提供。需要配套历史读取器与知序服务，候选文件存在不代表已安装生效，详见 [ChatGPT 同步说明](docs/CHATGPT_SYNC.md)。

1. 双击 `start.cmd`，浏览器打开 `http://127.0.0.1:4318`。程序会在后台运行。
2. 在「系统」检查 Vault、每日时间和时区。默认采用本次会话时区 `Asia/Singapore`，可改为 `Asia/Shanghai`。
3. 到「收集与加工」粘贴文字或导入 UTF-8 `.txt` / `.md`。标题可留空：普通保存优先采用首个 Markdown 标题，否则暂用首段文字；清理常见格式标记，超过 36 个可见字符时显示省略号，不调用模型。主动使用 AI 拆解时会发送所需原文，并在同一次回答中生成标题，可能产生费用；无需再给资料设置“仅本地/允许外发”分类。人工标题保持原样。「图片、PDF 和 Word」支持每份最多 50 MB（50,000,000 字节）的本地附件。图片/PDF不拆解，DOC仅保留原件；DOCX先在本机提取文字，核对覆盖范围后再主动提交AI。详见[附件与插图](docs/SOURCE_FILES.md)。
4. 无密钥时，可编辑、查找、手工整理个人观点、建立主题、主动加入学习、保留自己的回答和笔记。AI 批改会等待，不伪造评价。
5. 需要 AI 时，在「系统 → API 与能力设置 → API 配置中心」填写供应商地址、模型和密钥，勾选启用后测试连接；测试使用当前表单，成功后自动保存该能力，失败保留输入和原配置。测试可能产生费用，期间改动表单须重新测试；主动使用 AI 功能时，仅发送完成该操作所需的内容。联网研究还需搜索和网页读取两项能力。文本与嵌入地址/密钥填写完并离开输入框后，会自动向该服务读取模型目录；目录可搜索、手动刷新，始终可手填完整模型 ID。目录可读不等于模型可调用。
6. 双击 `stop.cmd` 停止由启动脚本启动的后台服务。关闭网页不会停止后台调度；关机或休眠时不保证执行，重启后补算今日安排。

换电脑需 Node.js 24，双击 `install.cmd` 安装锁定依赖；无需安装 Codex。本地缓存运行时只是已有环境的兼容入口。

### Token 用量与费用

在「系统 → 用量与费用」查看 token、每日趋势、按模型统计和请求明细；每日外部请求上限与月预算也在这里设置。可填写当前模型的输入、输出、缓存输入、嵌入及搜索单价，统一使用自己选定的货币单位。缺失用量或价格保留未知，历史费用不会因新单价被重算。完整口径和开源参考见 [用量与费用说明](docs/USAGE.md)。

### 日夜模式与强调色

左上角 Logo 右侧可切换日夜模式，首次跟随系统；手动选择保存在当前浏览器。深色主底色采用 `#111111`，取自 2026-09-21 实测的 [Recall Roadmap](https://docs.recall.it/recall-roadmap) 深色页面，卡片仍使用稍亮的灰色保持层次。

「系统 → 外观」提供强调色预设、取色器、颜色代码、日夜预览及恢复默认。点击保存后应用；为保持可读性，系统会调整颜色亮度。配色不影响资料、凭据或 AI 设置。

知识库的「知识使用建议」卡片默认显示简短说明，点击「查看依据」可展开完整依据；内容较多时在展开区域内滚动阅读，底部按钮仍可直接操作。

快速收集保存后会保留最近一次成功保存的资料标题和「查看整组」入口，使用保存回执中的实际资料编号；重复原文可直达已有资料。不会自动跳页，保存期间继续输入的新正文也会保留。入口在本次页面会话内保留，切换知识库或刷新浏览器后清除；原文保存不代表 AI 加工完成。

### 原文阅读与知识库筛选

原始资料正文在资料卡片、全文详情、检索摘录、正文预览、历史版本与练习材料选择中按基础 Markdown 阅读，支持标题、粗体、列表、引用、围栏代码、表格与安全网页链接。围栏内保持原样，HTML 不执行，外部图片不自动请求；原始资料详情只显示已绑定的本地插图。标题和元数据仍按普通文字显示。编辑框保留原文，阅读展示不会改写笔记。长代码块和宽表格在各自区域内横向滚动，聚焦后可用方向键查看。

知识库已有的「知识使用建议」「原始资料」「独立内容」栏可分别折叠，标题与数量保留；有未保存的资料编辑时须先保存。搜索和筛选时，建议只显示与精确命中内容或明确关联来源有关的项目，无相关建议时隐藏，清空筛选恢复。旧搜索或旧资料库的迟到结果不会追加到当前页面。

### 窗口与全屏

点击左侧栏的「« 收起导航」可隐藏整个侧栏，让正文使用更多空间；点击顶部左侧「☰」重新展开。宽屏下的选择保存在当前浏览器，刷新后继续生效。窄屏导航独立开合，选择页面或按 Escape 后收起，不改变宽屏偏好。

工作台内容随窗口宽度伸展，宽屏与全屏时利用侧栏以外的可用空间；缩小窗口后沿用移动端布局。新手引导收成小窗时，正文可利用释放的空间；收集页会展开原文和来源信息的可用宽度。刷新页面即可加载更新样式，无需重启服务。

### 启动速度与排查

关闭网页后服务仍在后台运行，再次双击快捷方式会先确认本机服务就绪，直接交给默认浏览器打开。仅在服务未运行时查找 Node 并启动；不会为了加速自动设置开机启动。桌面快捷方式继续指向 `start.ps1`，无需重建。

需要定位延迟时可运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Timing`。输出的 `ReadyMs` 为脚本开始到服务可用，`BrowserDispatchMs` 为调用默认浏览器的耗时，二者都**不代表浏览器已完成首屏显示**，也不包含 PowerShell 自身加载时间。`-NoBrowser` 仅取消打开浏览器，服务未运行时仍会启动服务；`-Port` 可指定端口，默认读取 `PORT`，未设置时为 4318。

测试结果和一秒目标的适用范围见 [启动性能说明](docs/STARTUP_PERFORMANCE.md)。

## 开发者快速开始

### Android 共用界面样机

Android 使用本会话起点的网页基线，已接入 txt/md 文件草稿、来源保留、版本查看与恢复、手机原文备份。第三阶段核心自动化已完成，当前仍是开发测试包；实际点击验收延期。功能包括本地学习计划、离线作答与结束练习、错题、主题学习包、独立练习库、本地引导和学习记录备份；离线答案只记录为“未评估”，不会自动评分或判定掌握。AI、自动同步与完整功能对齐仍在后续阶段。普通主分支网页更新不会自动同步到 App；网页版大版本更新后先由所有者确认是否同步。样机使用独立应用身份，设备验收只用合成资料。使用方式、固定基线和实际验证见 [Android 说明](docs/ANDROID_SHARED_UI.md)。

安装 Node.js 24 和 `package.json` 指定的 pnpm 11.19.0，在项目目录运行：

```sh
npm install --global pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm start
```

浏览器打开 `http://127.0.0.1:4318`。Linux/macOS 要保存供应商凭据，需先设置私有的 `LEARNING_MASTER_KEY`，参见 [.env.example](.env.example)；应用不自动加载 `.env`，显式加载可运行 `node --env-file=.env src/server.mjs`。没有供应商凭据也能使用本地资料功能。

```sh
pnpm verify
pnpm audit --prod --audit-level high
```

`verify` 运行语法/配置/上传边界检查、全部测试和本地中文检索检查。Linux/macOS 加密测试需临时随机主密钥，勿使用真实密钥。测试仅在 `.tmp/` 创建合成数据。网页版无需构建、无 TypeScript 类型检查；Android 样机有独立构建与 lint。真实模型和联网质量须单独验收。

参与修改请读 [CONTRIBUTING](CONTRIBUTING.md)；AI Agent 先读 [AGENTS](AGENTS.md)。版本、PR、自动检查和发布步骤见 [维护说明](docs/MAINTENANCE.md)，版本变化见 [CHANGELOG](CHANGELOG.md)，漏洞报告见 [SECURITY](SECURITY.md)。

## 原设计对齐更新

主题学习已接入成员顺序、前置知识和下一项入口；误解可单独练习；每轮批改只保存反馈，点击“结束本轮练习”后结算。知识库提供带理由的阶段建议，证据可展开查看，关联探索与缺失向量补建由用户主动选择。Vault 关系和主题属性可重新读回，Obsidian 链接改动先预览。逐项行为、证据和边界见 [本轮对齐记录](docs/DESIGN_ALIGNMENT_2026-09-29.md)。

开始学习时，触发按钮会暂时禁用，请等待材料页打开；重复点击不会新增学习会话。请求失败后，在当前页面重试同一学习操作会沿用防重标识，避免服务端已保存却未收到响应时重复新增；任一学习操作收到成功结果后，会清除旧的待确认标识；以后主动返回原知识开始仍保留新的独立学习记录。待确认标识只保留在当前页面内，刷新或关闭网页后不保留；不确定时可先在学习队列查看最近记录。

学习收尾的“确认写入”提交期间暂时禁用，成功后旧表单不会再次提交；失败后保留正文供重试。此保护仅覆盖当前表单，尚不覆盖刷新、重新打开或响应丢失后的重复确认。

问答提交后，浏览器会在本标签页保留已提交的问题和重试标识，正式库与练习库分别保存；刷新或服务重启后可继续同一请求。收到回答但记账失败时，先到“系统 → 用量与费用”补记，再回“问答与输出”保持输入不变重试，复用原回答且只保留一份草稿。成功后再次生成、修改输入或点击“另起新请求”属于新操作，可能再次计费，不按问题文本去重。未提交的修改不自动保存；关闭标签页、清除浏览器存储或旧客户端未传请求标识时，不保证找回原重试身份。

恢复备份中的“已完成”问答仍需匹配本机的已记账调用；本机有未决调用时先核对，其他调用的草稿不会替代原结果。备份把原回答标成本地草稿也不能绕过核对；核对失败时不改写现有草稿。历史完成记录若没有保存调用身份，草稿仍可在输出工作区查看、编辑，但不能通过旧请求标识推断其调用来源或重新发送；请保留恢复前安全备份供核对。

新手练习问答复用正式库的 AI 配置、预算和调用账本，按该账本核对成功响应后将草稿保存到练习库。若提示记账未完成，返回正式库“系统 → 用量与费用”补记，再回原练习重试；不会把正式资料或调用响应记录复制到练习库。

## 怎样试用一条完整流程

在今日页点击「开始新手引导」，或从左下角帮助进入。先选初中数学、读书思考、工作协作、Python 自学、数字生活，也可自行粘贴材料。五份内置材料以真实原文为主，模拟心得单独标明并保留出处与许可。教程配置 AI 并测试后，在独立练习库走完收集、实际拆解、选择知识、亲自作答、复习和引用输出；已有配置无需重复输入密钥。运行后可直接打开 [新手实操引导](http://127.0.0.1:4318/?onboarding=start)。

首次引导优先走 28 步核心体验：配置 AI → 收集加工 → 学习并确认理解 → 到期复习 → 检索输出 → 回顾完成。其他教程分为 12 个可选扩展专题，自行选择是否学习，不计入核心完成进度。核心完成后可直接回正式库；以后从今日页或帮助入口继续扩展阅读。已有步骤和进度保留，可暂停、继续和重置。

点击“定位操作位置”会打开对应内容并框选具体控件；前置操作尚未完成时，会提示并框选继续入口。窄屏下会为目标让出空间，位于引导窗内的时间按钮则保持展开。

复习页可前进一天或跳到下次复习；只改变练习学习时间，正式资料、电脑时间和 API 额度不变。练习与日常使用共用真实外部请求预算，连接测试也可能产生费用；模型请求由用户主动点击触发。原始回答、AI 建议和自己确认的理解分别保存。

数学、代码行为等事实型知识须先满足核验条件，必要时配置搜索与正文读取；不能改成个人观点绕过。语义嵌入和外部客户端仍可选。进度区分「已实操」「已看案例」「待配置」「未完成」；预设错题、提案等扩展案例不是本次 AI 结果或个人掌握。旧练习保留原材料与进度，确认重新练习后才可换场景。练习备份只能恢复到练习库。旧的「系统 → 备份与恢复 → 导入演示资料」仍会把旧示例加入当前所在的知识库。完整功能与完成条件见 [新手实操说明](docs/ONBOARDING.md)。

真实资料：保存原文→主动运行 AI 拆解（使用必要原文，无需重复授权）（默认不联网核验；可勾选执行，或生成后在资料详情手动点击「联网检验并找反例」）→查看拆解与待核验标记；主动核验后查看保存的网页正文摘录、支持/反对/限制和研究结论→决定留作参考、候选或主动学习→练习、复习、检索和输出。输出草稿不会自动进入个人知识层。

## 原始资料编辑

在知识库打开资料后点击「编辑原始资料」，或在「收集与加工」填写原文、选择 `.txt/.md` 文件预览，均可切换「Markdown 源码」与「可视化编辑」。两者修改同一份正文；无编辑切换或直接保存保留原格式，其他窗口先修改时仍会显示冲突并保留当前草稿。导入先逐份预览编辑，再确认保存；HTML、双链、行内公式等暂不能完整呈现的内容明确保留源码，远程图片不自动加载。适用范围与附件接入边界见 [Markdown 编辑说明](docs/MARKDOWN_EDITOR.md)。

## 从 ChatGPT 收集会话

「系统 → 能力设置 → MCP 接入」新增独立的 ChatGPT 开关。通过私有隧道连接 `src/mcp-chatgpt.mjs` 后，在对话里说“将该会话内容整理进知序”，即可把实际传入的角色原文和单独标注的整理摘要存入第一层原始资料。重试不重复新增或覆盖人工修改，不自动调用模型、联网核验或晋级。

保存已授权读取的历史聊天时，先让历史读取插件逐页读到末尾，再用短时本机引用导入；原文由两个本机服务直接传输，模型只提供独立摘要，知序核对发送方签名、快照和版本后保存。首次配置用于签名的本机持久密钥需单独批准；未配置时不会导入。隐藏分支与附件字节不在此范围，真实网页联动仍以实际回执和知序资料读回为准。

还可独立允许 ChatGPT 检索和读取知识库；读取内容会进入 ChatGPT 上下文，此项仍需单独开启，不会自动运行其他 AI 功能。两项权限默认关闭，可随时撤销。网页端仍需账户具备开发者模式与 OpenAI Secure MCP Tunnel 权限，电脑、知序和隧道需保持运行。连接方法见 [ChatGPT 连接说明](docs/CHATGPT_MCP.md)，运行后也可打开 [连接步骤](http://127.0.0.1:4318/chatgpt-setup.html)。本地验证不代表用户账户已连接。
